# Напоминания Task Calendar на iPhone

Дата: 2026-11-04. Первая часть iOS-приложения: только напоминания. Виджеты и прочее — следующими шагами.

## Зачем

Плагин Task Calendar в Obsidian хранит задачи в одном markdown-файле, и у задачи может быть время (`⏰ 2026-11-04 10:00-11:00`). Obsidian не умеет присылать системные уведомления: в нём нет такого API для плагинов (проверено по бандлу Obsidian 1.15: из Capacitor-плагинов есть App, Haptics, Filesystem и т.п., LocalNotifications нет). Попытка со скриптом Scriptable (`src/scriptable` в плагине) так и не была настроена Максом.

Нужно нативное приложение на Swift, которое Макс ставит на свой iPhone сам из Xcode (бесплатный Apple ID, переподпись раз в 7 дней). Своего бэкенда у приложения нет: всё хранится в файле задач в Obsidian. Без приложения плагин работает как раньше, только без напоминаний.

Главное требование Макса: напоминаниям можно доверять. Поменял что-то в Obsidian — напоминания поменялись сами, без его участия. Напоминание нельзя пропустить: взял телефон — увидел.

## Правила напоминаний (решения Макса)

- **Время задачи и есть напоминание.** Есть время — напоминание обязательно, ровно в начало слота. Нет времени — нет напоминания. Никаких «заранее», никаких напоминаний для задач только с датой или на весь день. У задачи 10:00–11:00 напоминание в 10:00.
- **Вид напоминания задаётся эмодзи перед временем**, у каждой задачи свой:
  - `⏰` — уведомление (как сейчас; все существующие задачи остаются уведомлениями);
  - `🚨` — будильник;
  - `🔕` — без напоминания.
  Плагин читает все три как время задачи; в календаре задача выглядит одинаково.
- **Задача и напоминание — разные вещи.** Задачу закрывает только целенаправленное нажатие кнопки Done. Ни смахивание, ни остановка будильника, ни боковая кнопка задачу не трогают.
- **Отложить сдвигает задачу в файле.** Новое время задачи = новое время напоминания, отдельного «времени напоминания» нет.
- **Повторы прекращаются в конце дня задачи** по границе дня плагина (`dayStartHour`, `DayBoundary`). Назавтра просроченная задача молчит и просто висит в Obsidian.
- Режим не глобальный: нет переключателя «все будильники / все уведомления». Только эмодзи на задаче.
- **Какие задачи напоминают** *(решение Claude)*: те, что календарь плагина показывает на времени, — незакрытые задачи со слотом (`openSlotted`). Подзадача, поставленная на время, в плагине и так вынимается из родителя (`setSlot`), поэтому отдельного правила для подзадач нет.
- Напоминания — только на iPhone. На Mac напоминаний нет; выбор вида напоминания в плагине работает на обеих платформах.

## Уведомление `⏰`

- Без звука. Телефон в кармане — не страшно; главное, увидеть, когда берёшь телефон.
- Заголовок — текст задачи без разметки (как `plainText` в плагине), ниже время: `10:00` или `10:00–11:00`.
- **Липкость.** Уведомление тихо повторяется, пока Макс не нажмёт Done или Отложить, но не дольше конца дня задачи. Повторы не копятся в списке: новое заменяет предыдущее (одна строка на задачу). Цель: разблокировал телефон — в течение минуты поверх всего появился баннер. Баннер висит, если у приложения стиль баннера «Постоянно» (ставится руками в настройках iOS, см. «Документация»).
  - Ограничение iOS: не больше 64 запланированных уведомлений на приложение, и приложение не просыпается в момент доставки. Поэтому повторы — заранее запланированная цепочка: каждую минуту первые ~15 минут, потом реже (например, раз в 5 минут, затем раз в 15). Цепочку продлевает каждое пробуждение приложения (каждый уход из Obsidian, открытие приложения, фоновое обновление). Точный шаг и деление бюджета 64 на задачи — решение строителя; ближайшие задачи важнее дальних.
  - `.customDismissAction`: если Макс смахнул уведомление, приложение (если iOS его разбудит) сразу показывает его снова. Это дополнение, не основа: iOS будит ненадёжно.
- **Тап** открывает Obsidian сразу на экране плагина (не просто vault). Наше приложение на долю секунды мелькнёт — обойти нельзя.
- **Кнопки при долгом нажатии** (английские, как интерфейс плагина): `Done`, `15 min`, `30 min`, `1 hour`. С иконками SF Symbols. Выполняются в фоне, без открытия приложения.
  - Done — задача получает статус done операцией плагина (`setStatus`), всё прочее, что плагин делает при закрытии, делает сам плагин-код.
  - Отложить — задача ставится на N минут **от текущего момента** с прежней длительностью: задача 10:00–11:00, нажал `30 min` в 10:07 → 10:37–11:37. *(Решение Claude)* Это ровно то, что делает перетаскивание задачи на новое время в календаре плагина (`setSlot`), со всеми его правилами: обрезка по границе дня, переход между Now и Soon, если новое время попало на другой день плагина. Отдельной операции «только сдвинуть время» нет — поведение одно.
  - *(Решение Claude)* **Кнопка никогда не проваливается молча.** Если задача с тех пор изменилась или переехала, приложение перечитывает файл и показывает актуальное напоминание (или убирает его, если задача уже закрыта / без времени). Если записать файл не удалось (например, телефон заблокирован и файл недоступен), напоминание остаётся на месте с подписью «Не получилось — открой Obsidian». Если проверка на телефоне покажет, что из заблокированного телефона писать нельзя, кнопки получают `.authenticationRequired` (iOS попросит Face ID).
- Не делаем: звук, ввод текста, «Начать», «На завтра», редактирование.

## Будильник `🚨` (AlarmKit, iOS 26+)

- В начало слота звонит будильник AlarmKit: весь экран, сквозь беззвучный режим и Focus, звонит, пока не остановят. На нём только заголовок — текст задачи (body у AlarmKit нет).
- Кнопки AlarmKit: системная «сдвинуть, чтобы остановить» (её не переименовать; боковая кнопка телефона делает то же) и одна своя.
  - **Стоп** только глушит. Задача не меняется. Сразу после остановки у задачи появляется то же тихое липкое уведомление, что у `⏰` (с Done / 15 min / 30 min / 1 hour, повторами до конца дня). Это след, а не лестница: звонит только будильник.
  - **Своя кнопка — «Отложить»** на интервал из настроек приложения (по умолчанию 30 минут). Сдвигает задачу в файле так же, как Отложить из уведомления, и будильник звонит в новое время. Выбора 15/30/60 на будильнике нет: AlarmKit даёт одну кнопку.
- Звук — свой файл в бандле приложения (системные рингтоны iOS недоступны, это подтверждено DTS; в iOS 27 ничего не изменилось). Пока любой; хороший подберём позже. Громкость — громкость звонка, управлять ей нельзя.
- Snooze у AlarmKit работает через countdown, а countdown требует widget extension с Live Activity — его нужно сделать, иначе система может гасить будильники.
- Риски (проверить на телефоне в первую очередь): подписывается ли AlarmKit и widget extension бесплатным аккаунтом; как ведут себя будильники при истёкшей подписи; жалобы на опоздания будильников в iOS 27.0.
- *(Решение Claude)* Порядок работ: сначала пробная сборка на телефоне (AlarmKit, widget extension, след-уведомление после «Стоп»), потом остальное. Если будильник на бесплатной подписи не собрать или след после «Стоп» не запускается надёжно, задача с `🚨` до починки напоминает как `⏰`, и Максу об этом сообщается. След можно и не запускать по «Стоп», а заранее поставить цепочку уведомлений с момента будильника — строитель выбирает надёжный способ.

## Как приложение узнаёт об изменениях

Это решено после исследования; других путей на бесплатном аккаунте нет.

- iOS не позволяет приложению постоянно работать в фоне и не будит его при изменении файла (DTS: «I'm not aware of any subsystem that will resume (or relaunch) you in response to file system changes»). Push, iCloud, Time Sensitive на бесплатном аккаунте недоступны. Беззвучное аудио и прочие keep-alive хаки Макс отверг.
- Файл задач на телефоне меняется только пока Obsidian на экране: правки Макса делаются в нём, а Obsidian Sync на iOS качает изменения с Mac только в foreground. Каждая такая сессия заканчивается уходом из Obsidian.
- **Основа:** личная автоматизация «Команд» «App → Obsidian → Is Closed» (срабатывает при уходе на главный экран, в другое приложение, при блокировке — не только при выгрузке) запускает App Intent приложения с `supportedModes = .background`: без открытия приложения и без баннера. Intent в основном target (security-scoped bookmark резолвится только в создавшем его процессе). Он перечитывает файл (повторно через 1–2 секунды, если файл ещё дописывается) и пересобирает все напоминания: новые добавляет, у перенесённых меняет время, лишние убирает.
- **Подстраховка:** то же при каждом открытии приложения и в `BGAppRefreshTask`.
- **Пока Макс в Obsidian** *(решение Claude: отложено)*: задача, поставленная прямо сейчас, время которой наступает, пока Obsidian ещё открыт, iOS неизвестна и не напомнит. Плагин не может узнать, что уже знает iOS, а напоминание «на всякий случай» дублировало бы уведомления. Случай редкий; в этот план не входит. Если окажется нужен — отдельная задача с досками.
- Макс настраивает один раз: автоматизацию и доступ приложения к папке vault.

## Код и репозитории

- **Отдельный репозиторий** `task-calendar-ios` (этот). Плагин `kudrmax/obsidian-task-tracker` подключён как git submodule. В Obsidian ни строчки Swift не попадает; приложение берёт из плагина только необходимый минимум.
- **Формат файла не переписывается на Swift.** В плагине появляется маленькая точка входа для телефона, по образцу `src/scriptable/main.ts`: «напоминания из текста файла», «закрыть задачу», «отложить задачу на N минут». Задача между чтением и действием опознаётся так же, как плагин опознаёт её сам (по месту и сырой строке, `TaskKey`); устарела — действие не выполняется. Сборка esbuild из submodule в один JS-файл, приложение выполняет его в JavaScriptCore. Swift-слой — только iOS: файлы, уведомления, будильники, intents.
- **Настройки формата** (путь к файлу задач, секции, маркеры, приоритеты, граница дня) приложение читает из настроек плагина в vault (`.obsidian/plugins/task-calendar/data.json`), а не дублирует у себя. Свои настройки приложения: доступ к папке vault и интервал Отложить у будильника.
- **Запись в файл** — через `NSFileCoordinator`, текст меняется операциями плагина. Obsidian подхватит изменение при следующем открытии, Sync разнесёт.
- Слои Swift-приложения по тем же принципам, что плагин: чистая логика отдельно от iOS-адаптеров (файл, UNUserNotificationCenter, AlarmKit, App Intents), классы и протоколы.

### Изменения в плагине (отдельная ветка плагина)

- Маркеры `🚨` и `🔕` рядом с `⏰` (`slotMarker`): парсер и запись строки понимают все три, вид напоминания — поле слота/задачи. `src/settings.ts` — общий контракт: менять осознанно.
- В интерфейсе плагина — выбор вида напоминания при постановке времени. Рисуется на досках (Claude Design) до реализации, на телефоне и на десктопе.
- Обработчик `obsidian://task-calendar?…`, который открывает экран плагина (по возможности на дне задачи). Сейчас этот action принимает ответ Google — нужно развести.
- Точка входа для телефона и её сборка.
- Скрипт Scriptable `Task Notifications` и `docs/plugin/notifications.md` убираются (им никто не пользуется) и заменяются новой страницей.

## Документация

`docs/plugin/` плагина, по-русски, в той же ветке: как поставить приложение из Xcode и переподписывать раз в 7 дней; дать доступ к папке vault; разрешить уведомления и будильники; стиль баннера «Постоянно»; приложение в разрешённых для каждого Focus (иначе тихое уведомление в фокусе не всплывёт); автоматизация «Obsidian закрыт» (Run Immediately, без уведомления; в iOS 27 — выключить Confirm Before Run, включить Allow Running When Locked); как проверить, что всё работает.

## Вид

Первая версия — системный вид iOS: заголовок, время, кнопки с иконками. Иконка приложения — любая заглушка. Дальше — доски в Claude Design для: уведомления и его раскрытого вида (возможна своя карточка задачи через Notification Content Extension), выбора вида напоминания в плагине. Возможности оформления: подзаголовок, картинка, иконки кнопок, своя карточка при долгом нажатии.

## Ограничения бесплатного аккаунта

Подпись живёт 7 дней, потом приложение не запускается (напоминания и кнопки перестают работать). Не больше 3 приложений на устройстве и 10 App ID в неделю; приложение, widget extension и (позже) content extension — отдельные App ID.

## Не цели

Виджеты (следующий этап), свой бэкенд или сервер, платный аккаунт разработчика, keep-alive хаки, звук у уведомлений, редактирование задач из приложения, напоминания без времени.

## Проверить на телефоне первым делом

1. Тихий App Intent из автоматизации «Is Closed» на iOS 26: без подтверждения, без баннера, успевает перечитать файл.
2. Запись в файл vault из фоновой кнопки уведомления, в том числе на заблокированном телефоне.
3. Повторы, заменяющие предыдущее уведомление, а не копящиеся.
4. AlarmKit и widget extension на бесплатной подписи; будильник при истёкшей подписи.

## Оставлено строителю

Шаг и бюджет цепочки повторов; формат идентификаторов напоминаний; как именно intent ждёт дописывания файла; устройство Swift-слоёв; имя URL-схемы приложения; как точка входа плагина собирается и обновляется в приложении.
