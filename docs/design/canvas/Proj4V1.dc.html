Живой блок в заметке. Вариант 1 — разделы сверху вниз, как в файле
Заметка «Окружение в новой стране» открыта в Obsidian. Под твоим текстом — задачи этого проекта, по разделам файла задач: Now, Soon, Backlog, Done. Заголовок раздела — как заголовок колонки плагина, секция внутри — как заголовок секции. Карточки — те же, что в плагине, без метки проекта: весь блок и есть проект. Тап по карточке — меню задачи, Enter — новая задача ниже, Tab — подзадача, перетаскивание между разделами переносит задачу по ленте. Пустых разделов нет. Done свёрнут, справа число сделанного.
