Task Calendar

A plugin for Obsidian, by Max Kudryashov.

A task list next to a day timeline. One markdown file in your vault is the truth: the plugin reads and writes it, and nothing else. Drag a task onto a time to plan it; your Google calendars and your work calendar show beside it.

Where things live

  • Your tasks: a markdown file in your Obsidian vault.
  • Your calendar events: read from Google Calendar (read-only) and from a file your phone exports; shown, never stored elsewhere.
  • Your Google login: a token kept in the plugin's settings file inside your vault.

There is no server behind the plugin. The source is on GitHub.
