# Блок 4. Быстрый ввод без перерисовок на каждую букву

Дата: 2026-11-03. Статус: спека. Обзор: `2026-11-03-perf-overview.md`. Делается после блока 3.

## Зачем

Когда задачи набираются подряд на телефоне, каждое Enter перерисовывает весь экран 3–4 раза, а каждая перерисовка переносит поле ввода в новый DOM-узел — отсюда blur/focus, прыжки клавиатуры и прокрутки. Каждая буква — 5–7 принудительных пересчётов раскладки и пересборка иконки места.

## Что сейчас (проверено по коду)

1. **Enter** (`src/ui/quick/QuickEntry.ts:216-219, 253-285`; `QuickEntryController.changed` `:494-507`):
   - рендер 1: строка встаёт в очередь, `movesRows` → полный `deps.render()` синхронно в keydown;
   - рендер 2: перед записью `await this.deps.fresh()` — перечитать файл и перерисовать;
   - рендер 3: после `createInPlace` ещё `fresh()`;
   - рендер 4: `finally { run.pending.shift(); this.changed() }` — ещё раз;
   - плюс эхо `modify` (блок 1 его убирает).
2. **Поле переезжает** (`QuickEntryController.ts:580-585, 284-303, 624-628`): `fieldIn` делает `row.appendChild(field.el)` в только что нарисованную строку; перенос фокусированного узла вызывает blur, `rendered()` зовёт `refocus()`, а `blurred()` прикрывает ложный blur таймером `setTimeout(…, 0)`.
3. **Каждая буква** (`QuickEntryController.ts:451-488, 510-516, 595-599`; `QuickBar.ts:124-138, 150-211, 217-221`): `onInput` → `changed` → `sync()` → `bar.show()` + `followBar()`, затем `reveal()` → `bringIntoSight()` + `followBar()` ещё раз. `followBar` — два `body.querySelector` + rect клавиатурной панели и строки статуса, rect поля, вида, прокрутки; `bar.follow()` сначала снимает 4 свойства, потом читает rect родителя; на Mac ещё два rect. `showPlace` пересоздаёт SVG иконки места; открытая панель пересобирается целиком с `markLongLabels` (`scrollWidth`).
4. **Прокрутка и `transitionend`** (`QuickEntryController.ts:142-154, 185-186`): оба — capture-обработчики на корне, каждый зовёт `followBar` без ограничения частоты; `transitionend` приходит по разу на каждое свойство каждого элемента, после перерисовки с анимацией карточек — пачка вызовов.
5. **`canIndent`/`canOutdent`** (`QuickEntry.ts:132-144`) на каждую букву дважды строят полный список карточек.
6. **Стоп-задержка `SETTLE_MS`** и прочие константы задержек в коде (`FloatingCard.ts:15, 86`, `Swipe.ts:46-52`) — не здесь, см. блок 6 (если трогать).

## Решения

### Enter — одна перерисовка

- Строка из очереди снимается **в той же перезагрузке**, которая показывает записанную карточку: `fresh()` после записи возвращает управление, когда новые задачи применены, и в том же применении очередь уже без этой строки. Итог: Enter → один синхронный сдвиг строк (как сейчас, чтобы ввод не ждал диска) + одна перерисовка после записи.
- `fresh()` **перед** записью остаётся, только если без него запись может уйти не в то место (план проверяет: блок 1 делает чтение дешёвым, но перерисовка всё равно лишняя — нужна свежая версия данных, а не перерисовка; если можно взять данные без рендера — так и делаем).

### Поле не переезжает

- `TaskList` при перерисовке сохраняет узел строки быстрого ввода (и поле внутри) и вставляет на новое место **тот же узел**, не перенося фокусированный элемент через отсоединение. Перенос DOM-узла внутри одного документа всё равно снимает фокус — поэтому строка с полем не удаляется и не создаётся заново, а остальные карточки рисуются вокруг неё (вставка до/после).
- Таймер `setTimeout(…, 0)` в `blurred()` убирается, когда ложного blur больше нет. Если на iOS он всё равно нужен — план фиксирует причину в коде одной строкой.

### Буква — один проход раскладки в кадр

- `sync`, `reveal` и `followBar` не выполняются сразу, а ставят один `requestAnimationFrame`: в нём сначала **все чтения** (rect поля, вида, прокрутки, клавиатурной панели, строки статуса, родителя панели), потом **все записи**. Несколько вызовов за кадр — один проход.
- Элементы клавиатурной панели и строки статуса находятся один раз на открытие поля (не `querySelector` на каждую букву); при их исчезновении — повторный поиск.
- Иконка места пересоздаётся, только если изменилось место; текст — только если изменился. Панель пересобирается, только если изменились её уровни.
- Прокрутка и `transitionend` идут через тот же один кадр; `transitionend` фильтруется по элементу и свойству (слайд колонок, оседание карточек), остальные игнорируются.
- `canIndent`/`canOutdent` берут список карточек один раз на изменение (кеш до следующей перерисовки).

## Тесты (фиксируют выигрыш)

- Enter с непустым текстом: число полных перерисовок вида после разрешения всех промисов ≤ 2 (синхронный сдвиг + после записи).
- После Enter узел поля ввода — тот же объект и `document.activeElement` не менялся (нет blur-событий).
- 10 событий `input` в одном кадре → один проход `followBar` и ноль `getBoundingClientRect` до кадра.
- Ввод букв без смены места не пересоздаёт SVG иконки.
- Пачка `transitionend` по несвязанным свойствам → ноль проходов.

## Не делаем

- Не меняем, где и как стоит панель над клавиатурой, анимации строк, правила уровней и мест.
