# Экран Projects: долгосрочное планирование

Макеты: https://claude.ai/artifact/LzBy4xktpJtsJPM7Ppo33G (холст «Проекты: дерево и задачи»: страницы «Экран», «Дерево: варианты» → вариант В, «Десктоп»).

## Цель

Дать второй взгляд на те же задачи — по смыслу, а не по времени. Воронка (Inbox / Backlog → Soon → Today → календарь) отвечает на «когда» и остаётся как есть. Новый экран Projects отвечает на «к чему это относится и что брать дальше».

## Зачем

Планирование дня в приложении удобное. Долгосрочное — нет:
- задачи по одной цели разбросаны по колонкам и проектам, связанное не видно рядом;
- проект плоский: дерматолог и ботинки лежат в одной куче;
- задачу трудно переложить в другой проект, приходится гадать, где она лежит, и открывать проекты по одному;
- 10 групп проектов постоянно висят в Backlog, их не переставить.

## Что меняется

1. **Проекты — одна сущность с любой вложенностью.** «Результат» — это просто вложенный проект. Проект — имя, которое живёт в приложении; заметка к нему не обязательна, её можно привязать. Проект создаётся быстро, как секция.
2. **У задачи может быть несколько проектов.** Сейчас ядро читает только первый `🗂️`. Задача показывается в каждом своём проекте; место в воронке у неё одно.
3. **Статус проекта считается сам, руками не ставится:**
   - активный — есть задача в Today, Soon или с датой;
   - ждёт — открытые задачи только в Backlog и Inbox (имя серым);
   - готово — все задачи сделаны, проект уходит в Done; новая задача возвращает его;
   - новый пустой проект ждёт, пока в нём не появится первая задача (как новая пустая секция).
4. **Inbox и проект независимы.** Задача может лежать в Inbox и уже иметь проект (надиктовал голосом и сразу указал проект). Inbox — «не обработано», а не «без проекта».
5. **Свёрнутая задача с подзадачами показывает следующую открытую подзадачу** — для любой задачи, как сейчас у результата. Знак `🎯`, Make result / Make task и страница Add to result уходят.
6. **Группировка по проектам внутри колонок воронки уходит** (группы в Backlog и Soon, переключатель Group by project). Значок папки на карточке остаётся.

## Экран Projects

- **Как попасть.** Плагин: в колёсике папка левее Inbox; тап по ней или свайп вправо с «Inbox и Soon». Окно колёсика стоит на одной папке — это своё положение, а не пара колонок. iPhone-приложение: вкладка Projects в таб-баре левее Inbox; свайп с Inbox тоже ведёт туда.
- **Слева — всё дерево проектов** (вариант В на холсте):
  - проект верхнего уровня — плитка на всю ширину колонки, скругление 10, только название, без иконок;
  - подпроекты любой глубины — строки текстом, каждый уровень сдвинут на 12 px, слева тонкая линия;
  - свёрнутая ветка: у плитки выглядывает слой, как у свёрнутой задачи; у строки — многоточие;
  - тап выбирает узел; повторный тап по выбранному сворачивает или разворачивает его ветку;
  - выбранное залито светлым целиком (как окно колёсика). Никаких обводок;
  - сверху «All» (все проекты), внизу «No project» и «Done»;
  - ждущие проекты — серым именем; отдельных заголовков Active и Waiting нет;
  - порядок проектов ручной, долгое нажатие переставляет; бросок со сдвигом вправо вкладывает проект в другой.
- **Между деревом и задачами** — разделитель с ручкой, как между Today и календарём.
- **Справа — задачи выбранного узла** обычными карточками. Над ними сегмент **By project / By stage**:
  - By project — секциями по подпроектам (сначала задачи самого проекта без заголовка); справа на карточке значок этапа (лоток, коробка Backlog, песочные часы, солнце) или дата;
  - By stage — секциями Today, Soon, Inbox, Backlog; над названием мелко подпроект задачи (двухстрочная карточка, как у свёрнутого результата).
- **Перенос в другой проект** — перетащить карточку на любую строку дерева; строка заливается цветом места броска (как плашка пустой секции под броском, без обводки). Место в воронке не меняется. Задержка над свёрнутой веткой раскрывает её.
- **Меню задачи** — обычное. Строка Project открывает выбор нескольких проектов галками; в конце «New project…».
- **Плюс**, брошенный в правую колонку, пишет задачу в этот проект; брошенный в дерево — создаёт проект или подпроект.
- **Поиск** из этого экрана показывает путь задачи («Дружба › iPhone»), чтобы дубли из разных проектов были видны рядом.
- **Десктоп** — то же, в метриках десктопной доски проектов; сегмент справа в строке заголовка.

## Пример

Утром Макс думает, что брать в работу. Свайп вправо с Inbox → Projects → «All», By stage: видно, что по «Спорту» ничего нет в Soon. Тап по «Окружение в Сербии», By project: «Активности как ЛШ» лежит в Backlog в «Где знакомиться» — меню → Soon. «Гугл как улучшить общение» на самом деле про «Small talk» в «Дружбе» — тянет карточку на эту строку дерева, задача остаётся в Soon, но теперь в другом проекте. Голосовая задача «Свидание: в каком формате искать» с проектом лежит в Inbox и видна в «Свидании» со значком лотка — её он разберёт позже в Inbox.

## Не трогаем

Воронку, экран дня, календарь, напоминания, быстрый ввод (кроме выбора нескольких проектов на кнопке Project).

## Открыто

- Где хранится список проектов и как записывается вложенность и несколько проектов у задачи — решает ядро, с условием «один файл задач остаётся правдой, всё работает руками и без сети».
- Что делать с существующими заметками-проектами (тег `#project`) и уже записанными `🎯`.
