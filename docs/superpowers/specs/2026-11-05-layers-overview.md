# Слои: обзор блоков

Дата: 2026-11-05. Статус: в работе.

## Что хотел Макс

Найти места, где перемешались бэкенд и фронтенд, и почистить их. Не одним большим вливанием, а логичными блоками, потому что параллельно работают другие агенты. Каждый блок: спека → план → реализация → вливание в master → релиз, потом следующий. Продуктово ничего не меняется: это рефакторинг.

## Источник

Ревью 05.11 (артефакт «Task Calendar: протечки слоёв», https://claude.ai/artifact/8pfAXS4edTGrLLTwuAJC99), пакеты P0–P10. Вывод ревью: по импортам слои держатся (`ui` не импортирует `domain` и `infrastructure`), но правила продукта местами считает UI, а домен и `application` местами смотрят не туда.

## Общие правила для всех блоков

- **Поведение не меняется.** Ни один экран, жест, запись в файл, формат `data.json` не меняется. Единственное исключение названо в блоке 3 (приоритет в тексте: UI выравнивается по правилу домена в краевых случаях, которых руками не набрать).
- **Вид не меняется** ни на пиксель.
- **Перенос правила = перенос его тестов.** Тест правила переезжает из `tests/ui` в `tests/domain` или `tests/application`; в UI остаётся тест, что UI берёт ответ у сервиса. Существующие тесты не ослабляются.
- **Контракты.** Почти каждый блок добавляет в `src/application/contracts.ts`. Макс разрешил менять его в этой серии; изменения только добавляют или переносят, без смены смысла существующих вызовов, кроме тех, что прямо названы в спеке.
- **Демо-сборка.** Новый метод `TaskService`/`CalendarService` нужен и в `tests/fakes/Demo*`; `npm run build:demo` зелёный.
- **Страж слоёв** (`tests/architecture.test.ts`, блок 1) держит список текущих нарушений. Каждый блок вычёркивает свои строки, добавлять нельзя.
- **Обе платформы.** Перед релизом — проверка в тестовом Obsidian: телефон (390×844, `app.emulateMobile(true)`) и окно Mac, светлая и тёмная. Для рефакторинга это проверка, что экран открывается, задачи и события на месте, затронутые жесты работают.
- **Каждый блок — своя ветка, свой план, свой релиз.** План пишется прямо перед блоком против свежего master: код между блоками меняется, план, написанный заранее, устарел бы.
