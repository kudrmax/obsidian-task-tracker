# Настройки

Settings → Task Calendar. Настройки лежат в `data.json` плагина и синхронизируются через Obsidian Sync. Не синхронизируются, а запоминаются на каждом устройстве отдельно: ширина списка (разделитель), положение колёсика и масштаб таймлайна.

## Tasks file

| Настройка | По умолчанию | Что значит |
|---|---|---|
| File path | `TODOs Tasks.md` | Файл задач. |
| Имена разделов | Inbox, Now, Soon, Backlog, Done | Текст заголовков `##`. |
| Due date marker | `📅` | Эмодзи срока. |
| Slot marker | `⏰` | Эмодзи времени (на iPhone — тихое уведомление). |
| Alarm marker | `🚨` | Эмодзи времени с будильником на iPhone. |
| Live Activity marker | `📌` | Эмодзи времени с карточкой на экране блокировки iPhone. |
| No-reminder marker | `🔕` | Эмодзи времени без напоминания. |
| Repeat marker | `🔁` | Эмодзи повтора. |

Сменишь эмодзи — старые строки в файле плагин перестанет узнавать: их надо поправить руками.

## Priorities

Уровни приоритета: префикс (одно слово) и цвет. По умолчанию `p1` красный, `p2` оранжевый. Порядок здесь — порядок плиток в меню. Префикс с пробелом, пустой или повторённый ничего не красит.

Цвет уровня можно выбрать тремя способами:

- **Один из шести кружков** (red, orange, yellow, green, teal, blue). Кружок залит ровно тем цветом, какой будет у карточки задачи на экране.
- **Радужный кружок** открывает системный выбор цвета. В нём сразу стоит текущий цвет уровня, его можно чуть подвинуть. Пока двигаешь, меняется карточка рядом; сохраняется цвет, когда закрываешь выбор.
- **Поле с кодом**: шесть цифр цвета, с `#` или без (`FF6A00` и `#ff6a00` — одно и то же). Сохраняется, когда уходишь из поля или жмёшь Enter; неверный код откатывается к прежнему.

Рядом с кружками — карточка задачи в выбранном цвете: фон, точка «в процессе» и время, как на экране. У шести готовых цветов свой оттенок в светлой и тёмной теме. Свой цвет одинаков в обеих, а фон карточки, точку и время плагин считает из него сам. Если ввести код одного из шести цветов, уровень станет этим готовым цветом.

## Sections

- **Presets** — заготовки секций, которые предлагает меню Section (по умолчанию Morning, Afternoon, Evening). Переставляются ручкой.
- **No section** — имя заголовка над задачами вне секций.

## Cards

Высота карточки (28–40, по умолчанию 35) и зазор между карточками (по умолчанию 2).

## Timeline

| Настройка | По умолчанию | Что значит |
|---|---|---|
| Long press delay | 250 мс | Через сколько касание становится перетаскиванием. |
| Day starts at | 5:00 | До этого часа ещё вчера. От него считаются «сегодня», сроки и таймлайн. |
| Scroll to hour | 9 | На каком часе открывается не сегодняшний день. |
| Zoom levels | 28, 56, 112, 224 | Высоты часа в пикселях; щипок ходит от «весь день» до самой крупной. |

## Calendar sources

- **Stale after** (180 минут) — когда источник получает оранжевую точку.
- **Google Calendar** — Client id, Client secret, Log in / Log out, Refresh interval (60 секунд, 0 — без таймера), галочки календарей. Как получить ключи — [README](../../README.md#google-calendar).
- **Work calendar** — File path (`calendar/work.json`), Calendars (какие календари брать из файла, пусто — все), Scriptable script → Copy (скрипт для Scriptable). Подробно — [Рабочий календарь на iPhone](work-calendar.md).
