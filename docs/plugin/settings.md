# Настройки

Settings → Task Calendar. Настройки лежат в `data.json` плагина и синхронизируются через Obsidian Sync. Не синхронизируются, а запоминаются на каждом устройстве отдельно: ширина списка (разделитель), положение колёсика и масштаб таймлайна.

На главном экране только то, что меняют, пока пользуются плагином: приоритеты, метки, секции, карточки. Всё, что настраивают один раз, — в разделе **More**: три строки со стрелкой, каждая открывает свою страницу (Calendars, Day and timeline, Tasks file). Закрыл страницу — вернулся в настройки. Закрылись сами настройки (или плагин выключили) — страница закрылась вместе с ними.

## Priorities

Уровни приоритета: префикс (одно слово) и цвет. По умолчанию `p1` красный, `p2` оранжевый. Порядок здесь — порядок плиток в меню; уровень переставляется ручкой слева. Префикс с пробелом, пустой или повторённый ничего не красит.

Цвет уровня можно выбрать тремя способами:

- **Один из шести кружков** (red, orange, yellow, green, teal, blue). Кружок залит ровно тем цветом, какой будет у карточки задачи на экране.
- **Радужный кружок** открывает системный выбор цвета. В нём сразу стоит текущий цвет уровня, его можно чуть подвинуть. Пока двигаешь, меняется карточка рядом; сохраняется цвет, когда закрываешь выбор.
- **Поле с кодом**: шесть цифр цвета, с `#` или без (`FF6A00` и `#ff6a00` — одно и то же). Сохраняется, когда уходишь из поля или жмёшь Enter; неверный код откатывается к прежнему.

Рядом с кружками — карточка задачи в выбранном цвете: фон, точка «в процессе» и время, как на экране. У шести готовых цветов свой оттенок в светлой и тёмной теме. Свой цвет одинаков в обеих, а фон карточки, точку и время плагин считает из него сам. Если ввести код одного из шести цветов, уровень станет этим готовым цветом.

## Labels

Метки: имя и цвет. Строка устроена как у приоритетов: ручка перестановки, имя, шесть кружков, радужный кружок, код цвета, карточка в этом цвете, корзина. Имя пишут с пробелами («Важное и срочное»), в тег оно уходит с подчёркиваниями (`#label/Важное_и_срочное`). Порядок здесь — порядок плиток в меню и цветов на карточке с несколькими метками. **Add label** добавляет метку `Label_<n>` в первом свободном цвете. Пустое, повторённое имя или имя с `#` ничего не красит.

**Several labels** — как красится карточка с несколькими метками:

- **Stripes** (по умолчанию) — частые косые полоски цветов меток по очереди.
- **Blend** — цвета плавно перетекают слева направо.

Точка «в процессе» и время на такой карточке — цвета первой метки.

## Sections

- **Presets** — заготовки секций, которые предлагает меню Section (по умолчанию Morning, Afternoon, Evening). Переставляются ручкой.
- **No section** — имя заголовка над задачами вне секций.

## Cards

Высота карточки (28–40, по умолчанию 35) и зазор между карточками (0–10, по умолчанию 2).

## More → Calendars

- **Calendars shown** — все календари из файлов календарей, по аккаунтам, с переключателем у каждого. Новый календарь виден, пока его не выключишь. Тот же выбор действует для напоминаний на iPhone. Подробно — [Календари](calendars.md).
- **Google Calendar** — Account (вошёл ли ты, Log in / Log out; пока нет OAuth-клиента, строка просит сначала заполнить его ниже), Client id, Client secret, Refresh interval (60 секунд, 0 — без таймера). Как получить ключи — [README](../../README.md#google-calendar).
- **Work calendar** — File path (`calendar/work.json`), Scriptable script → Copy (скрипт для Scriptable). Подробно — [Рабочий календарь на iPhone](work-calendar.md).
- **All sources → Stale after** (180 минут) — сколько файл календарей считается свежим: старше — берётся следующий источник, а если свежих нет, горит оранжевая точка.

## More → Day and timeline

| Настройка | По умолчанию | Что значит |
|---|---|---|
| Day starts at | 5:00 | До этого часа ещё вчера. От него считаются «сегодня», сроки и таймлайн. |
| Scroll to hour | 9 | На каком часе открывается не сегодняшний день. |
| Long press delay | 250 мс | Через сколько касание становится перетаскиванием. |
| Zoom levels | 28, 56, 112, 224 | Высоты часа в пикселях; щипок ходит от «весь день» до самой крупной. |

## More → Tasks file

Строка показывает путь к файлу задач.

| Настройка | По умолчанию | Что значит |
|---|---|---|
| File path | `TODOs Tasks.md` | Файл задач. |
| Section headings: Inbox, Now, Soon, Backlog, Done | так же | Текст заголовков `##`. Этими же именами списки названы в заголовках колонок, на кнопке места и в её плитках. |
| Due date marker | `📅` | Эмодзи срока. |
| Slot marker | `⏰` | Эмодзи времени (на iPhone — тихое уведомление). |
| Alarm marker | `🚨` | Эмодзи времени с будильником на iPhone. |
| Live Activity marker | `📌` | Эмодзи времени с карточкой на экране блокировки iPhone. |
| No-reminder marker | `🔕` | Эмодзи времени без напоминания. |
| Repeat marker | `🔁` | Эмодзи повтора. |
| Collapsed marker | `📁` | Эмодзи задачи со свёрнутыми подзадачами. |
| Label tag | `label` | Папка тега меток: `#label/<имя>`. Одно слово. |
| Project tag | `#project` | Тег, который делает заметку проектом: в свойствах или в тексте. Одно слово, плагин сам допишет `#`. Если в Obsidian выключено Files and links → Automatically update internal links, под полем написано, что его надо включить: иначе переименование заметки проекта ломает ссылки `🗂️` у задач. |

Сменишь эмодзи — старые строки в файле плагин перестанет узнавать: их надо поправить руками.

## Обновления плагина

Новая версия приходит через BRAT на Mac, а на iPhone её привозит Sync. Плагин сам замечает, что его файлы в папке поменялись, и перезагружается: через пару секунд после того, как Sync закончил писать, или когда возвращаешься в Obsidian. Перезапускать Obsidian на телефоне не нужно. Раньше телефон работал на старом коде до перезапуска, и старый код, не знавший новых меток, портил строки, например дописывал второе время к задаче с `📌`.
