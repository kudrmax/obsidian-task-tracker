# Ассистент

Ассистент отправляет часть задач языковой модели вместе с вопросом и показывает ответ. Ничего не двигает и не подсвечивает: только отвечает. Сейчас модель — Claude по подписке Claude Code, и работает ассистент только в Obsidian на Mac.

## Best task

В меню «⋯» (капсула слева внизу) третья строка — **Best task**, со значком искорок. Она спрашивает: из задач в Today и Soon какая одна даст больше всего, если сделать только её, и почему.

1. Нажал Best task — меню закрылось, а «⋯» превратился в маленькое крутящееся кольцо. Пока оно крутится, плагином можно пользоваться как обычно: листать, перетаскивать, открывать меню, печатать. Модель думает в отдельном процессе.
2. Пришёл ответ — посреди окна Obsidian открывается окошко: сверху мелко «Best task», под ним карточка выбранной задачи (так же, как в списке; это может быть и подзадача — шаг тоже хороший ответ), под карточкой объяснение модели, внизу Close. Закрывается кнопкой Close, клавишей Esc или кликом мимо окошка. Окошко придёт, даже если вкладку плагина за это время закрыли.
3. Передумал ждать — снова открыть «⋯»: вместо Best task там строка **Stop** с тем же кольцом. Нажал — запрос остановлен, кольцо пропало, ничего не показывается. Если ответ пришёл, пока меню открыто, строка сама снова становится Best task: старый Stop не нажмётся и нового запроса не начнёт.

Что уходит модели: открытые задачи Today и Soon с подзадачами — название, список, в работе ли, приоритет, срок, время, проекты, метки и чья это подзадача. Описания задач не отправляются. Модель называет задачу по её номеру в запросе, а не по названию, так что задачу, которую за время ожидания переименовали или перенесли, плагин всё равно найдёт.

Today и Soon пусты — запроса нет, окошко сразу говорит «Today and Soon have no open tasks.».

## Когда что-то не так

Ошибка показывается в том же окошке: заголовок «Couldn't find the best task» и одна фраза, что делать. Подробности — в консоли разработчика Obsidian (⌥⌘I).

| Что пишет окошко | Что случилось | Что делать |
|---|---|---|
| Claude Code isn't installed… | Плагин не нашёл программу `claude`. | Установить Claude Code или указать путь в Settings → Assistant. |
| Claude Code isn't signed in… | Claude Code не залогинен. | В Терминале запустить `claude` и войти. |
| Claude refused… | Подписка или аккаунт сейчас без доступа, либо Claude Code настроен на API-ключ, а не на подписку. | Проверить подписку на claude.ai; убрать API-ключ из настроек Claude Code. |
| Claude's usage limit is reached… | Кончился лимит подписки. | Подождать, пока он обновится. |
| Claude is overloaded… | Claude перегружен. | Повторить через минуту. |
| Can't reach Claude… | Нет сети или Claude недоступен из этой сети. | Проверить интернет или VPN. |
| Claude doesn't know the model… | В настройках указана модель, которой нет. | Выбрать sonnet, opus или haiku. |
| Claude didn't answer in … | Ответа не было дольше, чем указано в Timeout. | Повторить или увеличить Timeout. |
| Claude's answer didn't name one of the tasks… | Модель ответила не по форме. | Повторить. |
| That task was closed while Claude was thinking. | Выбранную задачу за время ожидания закрыли или удалили. | Спросить ещё раз. |
| Claude failed. The details are in the console. | Другая ошибка Claude Code, без своего объяснения. | Открыть консоль разработчика (⌥⌘I) и посмотреть строку «Task Calendar assistant». |
| No model is set for the assistant. Choose one in Settings → Assistant. | В настройках выбрана модель, которой плагин не знает. | Выбрать модель в Settings → Assistant. |

Ассистент всегда работает через подписку: если Claude Code собрался бы платить по API-ключу, запрос останавливается раньше, чем модель ответит («Claude refused…»). Переменные `ANTHROPIC_API_KEY` и `ANTHROPIC_AUTH_TOKEN` плагин в Claude Code не передаёт.

## На iPhone

В Obsidian на iPhone строки Best task нет, и ничего для ассистента не загружается. Страница Settings → Assistant там открывается: под выбором модели написано «Claude works in Obsidian on the Mac.», настроек Claude (модель, путь) нет, а Timeout и промпты можно править: они синхронизируются на Mac.

## Что нужно на Mac

Claude Code, установленный и залогиненный по подписке. Плагин ищет `claude` сам: `/opt/homebrew/bin/claude`, потом `/usr/local/bin/claude`, потом `~/.local/bin/claude`. Найденный путь виден в Settings → Assistant под полем Path to claude; если там «Not found» — путь нужно вписать. Как проверить: открыть Best task на нескольких задачах — должно прийти окошко с карточкой.
