# Task Calendar

Плагин Obsidian: короткий список дел рядом с календарём дня. Работает на iPhone и на Mac. Эта страница — суть: прочитав её, можно понять, как устроен рабочий день с плагином и о чём идёт речь, когда просят что-то сделать с задачами. Подробности — на внутренних страницах (список внизу).

## Суть

Task Calendar — не база задач, а путь задачи от «пришла мысль» до «сделано»: Inbox и Backlog → Soon → Now → время в календаре → Done. Всё в нём служит одному: в любой момент видеть короткий список того, что делать сейчас, и делать задачи одну за другой, не решая каждый раз заново, что дальше.

На этом держатся главные фичи:

1. **Воронка вместо полей.** Место задачи и есть ответ на вопрос «когда»: Inbox — не решено, Backlog — когда-нибудь, Soon — не сегодня, Now — сегодня, календарь — в это время. Планировать — значит переносить задачу из места в место.
2. **Сегодня рядом с календарём.** Now — короткий список дня, рядом шкала дня со встречами. Задачу кладут на время прямо между встречами.
3. **Виден только следующий шаг.** Задачу из нескольких шагов сворачивают, и в списке и на календаре остаётся одна карточка: её первый открытый шаг. Сделал шаг, нажал Done, и на его месте сразу встаёт следующий. Большое дело проходится шаг за шагом, без возврата к плану.
4. **Сделанное исчезает, прошлое не копится.** Done сразу убирает задачу с экрана. Несделанное вчера утром само стоит в Now. Просрочки нет.
5. **Проекты отвечают «к чему», воронка отвечает «когда».** Проект — отметка на задаче поверх воронки. Выбранный проект фильтрует весь экран, вид «По проектам» показывает, где в воронке каждая его задача.
6. **Записать за секунду.** Плюс в любое место списка или на время календаря. С iPhone — текстом или голосом, не открывая Obsidian.
7. **Напоминание ровно в начало.** Задача со временем приходит на iPhone карточкой на экран блокировки, уведомлением или будильником. Из напоминания её закрывают или откладывают.

Каждая из этих частей подробно описана ниже.

## Как устроен

Здесь инструмент описан по частям: что в нём есть, что каждая часть значит и как себя ведёт. Как им пользоваться, решает сам человек: плагин не навязывает способ планировать.

### Задача

Задача — одно дело в общем списке. У неё есть название и, если нужно, дата, время, проекты, повтор, приоритет или метки, подзадачи и описание. На экране задача — карточка: капсула с названием, справа дата и значки.

Состояния задачи:

- **открыта**;
- **в процессе** — точка слева на карточке; место задачи от этого не меняется;
- **сделана** (Done);
- **не будет сделана** (Won’t do).

Сделанная и отменённая задача сразу уходит с экрана в историю Done. Найти её можно поиском.

Чекбоксов на экране нет. С задачей работают через её меню (тап по карточке) или перетаскиванием (долгое нажатие). Любое действие отменяется кнопкой отмены.

Все задачи хранятся в одном файле в Obsidian, своей базы у плагина нет. Файл можно править руками или агентом: плагин сразу покажет изменения.

### Лента: где стоит задача

Каждая открытая задача стоит ровно в одном месте ленты:

```
Inbox / Backlog  →  Soon  →  Now (сегодня)  →  календарь дня
```

| Место | Что значит |
|---|---|
| Inbox | Записано, но ещё не решено, когда делать. Без даты и времени. |
| Backlog | Когда-нибудь: сохранено, но не скоро. Без даты и времени. На экране — нижняя половина колонки Inbox. |
| Soon | Не сегодня: либо без даты, либо с датой в будущем. Колонка Soon показывает только задачи без даты; задачи с датой видны в колонке своего дня. |
| Now (Today) | Сегодня. |
| Календарь дня | У задачи есть время в этот день: она стоит на шкале дня рядом со встречами. |

- Задачу переносят из места в место перетаскиванием между колонками или из меню: Today, Tomorrow, Pick a date.
- Новая задача пишется сразу туда, где будет: плюсом в нужную колонку, между карточками или на время в календаре.
- Порядок задач в каждом месте ручной. Каким его сложили перетаскиванием, таким он и остаётся: плагин ничего не сортирует, ни по дате, ни по приоритету.
- Экран — окно на две соседние колонки ленты: Inbox и Soon, Soon и Now, Now и календарь. Окно двигают свайпом или колёсиком внизу. Есть и другие виды: все колонки сразу (только Mac), строки друг под другом, задачи по проектам.

### Дни, даты и время

- **Дата** — день, в который задачу собираются сделать. Это не дедлайн. Задача с датой лежит в Soon и видна в колонке своего дня, а когда этот день наступает, сама переходит в Now.
- **Колонка дня** показывает задачи выбранного дня: сегодня это Now, в другой день — задачи с его датой. Дни листают стрелками над колонкой или свайпом вправо от календаря.
- **Время** — место задачи на шкале дня, с длительностью или без. Время появляется, только когда задачу кладут на календарь; из текста задачи оно не распознаётся.
- **Прошлое не копится.** Несделанная задача с прошедшей датой утром получает сегодняшнюю и стоит в Now. Время прошедшего дня стирается: время — это план на один день. Просроченных задач не бывает.
- Сегодняшняя несделанная задача, чьё время уже прошло, едет на календаре за линией «сейчас».
- **День начинается не в полночь**, а в час из настроек, обычно в 5:00. В 2 часа ночи ещё идёт вчерашний день.

### Проекты

Лента отвечает на вопрос «когда делать», проект — на вопрос «к чему это относится». Это две независимые оси.

- **Проект — отметка на задаче, а не место.** Задача из проекта стоит в своём месте ленты, как любая другая. Перенос по ленте не меняет её проекты, смена проекта не двигает её по ленте.
- **Проектов у задачи может быть несколько**, и она видна в каждом. Задачи без проекта собраны под «No project».
- **Проекты вкладываются друг в друга** на любую глубину: «Окружение в Сербии» → «Где знакомиться» → «Приложения для знакомств». Подпроект — часть родителя: выбрав родителя, видишь и задачи его подпроектов. Галочка Subprojects в меню вида оставляет только задачи самого проекта.
- **Папка** — проект, который только объединяет подпроекты. Своих задач у неё не бывает.
- **У подзадачи своих проектов нет**: она относится к проектам своей задачи.
- **Статус проекта никто не ставит**, он считается по задачам проекта и его подпроектов. Есть открытая задача в любом месте ленты — проект живой. Задач ещё нет — имя серое. Все задачи сделаны — проект уходит в Done, а новая задача возвращает его на место.
- **Проект — имя, а не заметка.** К проекту можно привязать заметку для мыслей; в её конце тогда виден блок с задачами проекта. Сами задачи всё равно живут в общем списке.
- **Панель проектов** (кнопка с папкой слева сверху) — дерево проектов. Выбранный проект фильтрует весь экран: во всех колонках и на календаре остаются только его задачи, встречи видны все. Вид экрана от выбора не меняется.
- **Вид «По проектам»** раскладывает задачи проекта по подпроектам, а внутри каждого — по ленте. Значок справа на карточке показывает, где задача в ленте: Inbox, Backlog, Soon, сегодня или дата.
- **Сделанные задачи** уходят в историю вместе с проектом — это история проекта.
- Проекты заводят, переименовывают, переставляют и вкладывают прямо в дереве. **Удаление проекта задачи не трогает**: они только теряют эту отметку.

### Задача изнутри: подзадачи и описание

- **Подзадача** — обычная задача внутри другой: свой статус, дата, приоритет, повтор. Вложенность любая. На экране подзадачи стоят под задачей веткой.
- **Свёрнутая задача: виден только следующий шаг.** Задачу с подзадачами сворачивают тапом по счётчику «1/3». Её карточка становится двухстрочной: сверху мелко название задачи, крупно — её первый открытый шаг (на любой глубине вложенности). Done, In progress и Won’t do в меню такой карточки относятся к этому шагу: Done закрывает шаг, и на его месте сразу встаёт следующий. Остальное меню (перенос, проект, приоритет) — для всей задачи. На календаре блок свёрнутой задачи называется её следующим шагом. Так большая задача занимает одну карточку и показывает только то, что делать прямо сейчас. Свёрнутость хранится в самой задаче и едет с ней: в другое место ленты, на календарь, в копию повтора.
- Сделанная подзадача пропадает с экрана, но остаётся внутри задачи. Сама задача закрывается вместе со всеми подзадачами.
- Подзадачу можно унести в другое место ленты или на календарь. Тогда она становится отдельной задачей и сохраняет проекты родителя.
- **Описание** — свободный текст под задачей: детали, ссылки, мысли. Открывается вместе с задачей на весь экран; его начало видно над меню задачи.

### Секции

Задачи внутри Inbox, Soon, Now и Backlog можно собрать в группы с именем: «Morning», «Evening», «Экскурсия».

- Секция живёт, пока в ней есть задачи: когда из неё унесли последнюю, она исчезает сама. Пустую секцию можно завести заранее.
- Секции с одинаковым именем связаны: задача из секции «Evening» в Soon в свой день встаёт в секцию «Evening» в Now.
- Задача, которой поставили время на календаре, выходит из своей секции.

### Повтор

Повтор бывает двух видов:

- **по расписанию**: каждые N дней, по дням недели, по числу месяца;
- **от последнего раза**: через N дней, недель или месяцев после того, как сделал.

Когда повторяющуюся задачу закрывают, в Soon встаёт её копия на следующую дату: то же название, приоритет, метки, описание, подзадачи снова открыты, времени нет. Копия всегда одна: пропущенные разы не копятся, будущие не расставляются заранее. Won’t do пропускает этот раз, Stop заканчивает повтор. Повторяться может и подзадача.

### Приоритет и метки

Приоритет (по умолчанию два уровня, красный и оранжевый) и метки только красят карточку. Сортировки по ним нет. У задачи бывает либо приоритет, либо метки; меток может быть несколько.

### Календари

На шкале дня рядом с задачами видны встречи Google Calendar, рабочего календаря и остальных календарей iPhone. Встречи только показываются: двигать, создавать и менять их нельзя. Какие календари видны, выбирается в окне источников.

### Напоминания

Задача со временем напоминает о себе на iPhone в момент начала. Это делает приложение Tasks. Вид напоминания выбирается в меню задачи (Reminder):

- карточка на экране блокировки — так по умолчанию;
- тихое уведомление;
- будильник;
- без напоминания.

Из напоминания задачу можно закрыть или отложить: на 15 минут, 30 минут, час или до конца ближайшей встречи. Задача без времени не напоминает.

### Где работает

- **Obsidian на iPhone и на Mac** — один и тот же экран. На телефоне всё делается пальцем; на Mac — мышью и трекпадом, плюс клавиши и действия сразу над несколькими задачами.
- **Приложение Tasks на iPhone** — тот же экран и те же правила без Obsidian, плюс напоминания.
- **Быстрый ввод с iPhone** — задача текстом или голосом в Inbox, Now, Soon или Backlog, не открывая Obsidian: с экрана блокировки, через Siri, кнопкой действия.
- **Поиск** находит любую задачу, в том числе сделанную.
- Устройства видят изменения друг друга через Obsidian Sync.

### Чего в инструменте нет

- дедлайнов и просрочки;
- автоматической сортировки;
- распознавания даты и времени из текста задачи;
- задач, разбросанных по заметкам: все задачи в одном списке.

## Как выглядит день

- **Утро.** Плагин сам перенёс в Now всё, что назначено на сегодня, и вернул в Now вчерашнее несделанное. Открываешь экран «Now и календарь»: слева список дня, справа таймлайн со встречами.
- **Планирование.** Перетаскиваешь задачи из Now на свободные места календаря. Что не влезло — тапом по карточке переносишь на завтра (Tomorrow) или на выбранный день.
- **В течение дня.** Новое быстро пишешь плюсом: в Inbox, если не ясно, что с этим делать; сразу в Now, если это сегодня. Сделал — тап по карточке → Done.
- **Разбор.** Время от времени листаешь колёсико к Inbox и Soon и раскладываешь: из Inbox в Soon или Now, в Backlog — что не скоро, на конкретный день — через меню.
- **Долгий план.** Кнопка с папкой слева сверху — панель проектов. Выбрал проект — весь экран показывает только его задачи, удобнее всего «Строками»: что в Inbox, что в Soon, что ждёт в Backlog. Отсюда решаешь, что брать дальше, и перекладываешь задачу в другой проект, перетащив её на строку дерева. Крестик у имени проекта — снова все задачи.
- **Вечер.** Можно открыть завтрашний день и разложить его задачи по секциям; утром они будут в Now в тех же секциях.

## Файл в двух словах

```markdown
## Inbox
- [ ] Придумать подарок

## Projects
- Окружение в Сербии
	- Где знакомиться
- Работа 🗃️
	- Отчёты

## Now
- [ ] p1 Позвонить в банк
- [/] Написать отчёт 🗂️ Отчёты 📌 2026-11-05 14:00-15:30
### Evening
- [ ] Полить цветы 📅 2026-11-05 🔁 every 3 days when done

## Soon
- [ ] Купить билеты 📅 2026-11-08
- [ ] Найти, где знакомиться 🗂️ Где знакомиться 📁
	- [ ] Посмотреть приложения
	- [ ] Сходить на встречу экспатов
- [ ] Разобрать почту

## Backlog
- [ ] Выучить испанский

## Done
- [x] Сдать анализы
```

- Пять разделов второго уровня: **Inbox** — не разобрано, **Now** — сегодня, **Soon** — не сегодня (без даты или с будущей датой), **Backlog** — когда-нибудь, **Done** — сделанное и отменённое.
- `## Projects` — дерево проектов: вложенный список имён, отступ — подпроект, `🗃️` после имени — папка.
- Статусы: `[ ]` открыта, `[/]` в процессе, `[x]` сделана, `[-]` не будет сделана.
- Поля в конце строки: `📅` срок, `⏰` время на календаре (вместо него `📌`, `🚨` или `🔕` — то же время с другим видом напоминания), `🔁` повтор, `🗂️ Имя` — проект (по одному на проект), `📁` — подзадачи свёрнуты. Первое слово `p1`, `p2` — приоритет. Теги `#label/<имя>` — метки: их может быть несколько, вместо приоритета.
- Вложенные задачи — подзадачи; вложенные строки без чекбокса — описание задачи.
- `### Имя` внутри раздела — секция.

Подробно, со всеми правилами, — [Файл задач](file.md).

## Слова

| Слово | Что значит |
|---|---|
| Inbox | Раздел и колонка: задача, про которую ещё непонятно, когда её делать. Без срока и без времени. |
| Backlog | Раздел и нижняя половина первой колонки: сохранено, но не скоро. Без срока и без времени. |
| Soon | Раздел: не сегодня. Колонка Soon показывает только задачи Soon без даты; задачи Soon с датой видны в колонке своего дня. |
| Now | Раздел: сегодня. Колонка дня на сегодня показывает Now. |
| Колонка дня | Список выбранного дня. Сегодня — Now, другой день — задачи с этой датой. |
| Календарь, таймлайн | Шкала выбранного дня: встречи и задачи со временем. |
| Срок, дата, `📅` | День, в который задачу надо сделать. |
| Время, слот, `⏰` | Время на календаре на конкретный день. Ставит плагин, когда задачу кладут на таймлайн. |
| Секция | `### Имя` внутри Inbox, Soon, Now или Backlog — группа задач. |
| Проект, `🗂️` | Имя в разделе `## Projects` файла задач; проекты вкладываются друг в друга на любую глубину. Задача в проекте, если в её строке `🗂️ Имя`; проектов у задачи может быть несколько. Заметка к проекту не обязательна: её можно привязать, тогда ссылка стоит в строке проекта. |
| Панель проектов | Дерево проектов за кнопкой с папкой: выбранный проект фильтрует весь экран, «All» — все задачи, без фильтра. Статус проекта (активный, ждёт, готово) считается сам. |
| Режим вида | Как разложены списки: две колонки, все колонки (Mac), строки, по проектам. Один на экран, меняется только кнопкой рядом с колёсиком; выбор проекта его не меняет. В её меню у проекта с подпроектами — галочка Subprojects: показывать ли задачи подпроектов. |
| Подзадача | Задача, вложенная под другую. |
| Описание | Строки без чекбокса под задачей. |
| Колёсико | Переключатель внизу экрана: Inbox, Soon, Now, календарь. |
| Плюс | Круглая кнопка внизу справа: новая задача. |
