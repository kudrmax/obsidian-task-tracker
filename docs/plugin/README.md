# Task Calendar

Плагин Obsidian: короткий список дел рядом с календарём дня. Работает на iPhone и на Mac. Эта страница — суть: прочитав её, можно понять, как устроен рабочий день с плагином и о чём идёт речь, когда просят что-то сделать с задачами. Подробности — на внутренних страницах (список внизу).

## Чем он не похож на обычный таск-менеджер

Обычный менеджер задач — это база задач с датами, дедлайнами, просрочкой, фильтрами и сортировкой. Task Calendar устроен иначе, и это главное, что нужно держать в голове.

1. **Задачи — это один markdown-файл.** `TODOs Tasks.md` в корне волта. Своей базы, кэша и скрытого состояния у плагина нет: всё, что он знает, записано в строках файла. Файл можно править руками в любой момент, плагин сразу это подхватит. Выключи плагин — останется обычный читаемый список дел.

2. **Задача движется по ленте слева направо, от «непонятно» к «на время».** Экран — это лента колонок:

   ```
   Inbox / Backlog  →  Soon  →  Now (сегодня)  →  календарь дня
   ```

   Планирование — это перетаскивание задачи из колонки в колонку, а не заполнение полей. Пришла мысль — в Inbox. Понял, что делать, но не сегодня — в Soon. Берёшь на сегодня — в Now. Решил, когда именно, — кладёшь на календарь, на конкретное время, рядом с реальными встречами.

3. **Now — это сегодня, и он короткий.** Now — не «всё, что горит», а маленький список того, что взято в работу на этот день. Задача с сегодняшней датой и задача в Now — одно и то же.

4. **Дата — это «сделать в этот день», а не дедлайн.** У задачи может быть срок `📅` — день, в который её надо сделать. Пока день не наступил, задача лежит в Soon и видна в колонке своего дня. Когда день наступил, она сама переезжает в Now.

5. **Просрочки нет.** Прошлое не копится. Невыполненная задача с прошедшей датой утром просто получает сегодняшнюю. Время `⏰`, на которое задачу клали в календаре, после конца дня стирается: время — это план на конкретный день, а не обязательство. Никаких красных «просрочено» и хвостов из вчера.

6. **Время ставится только руками на календаре.** Задача получает время, только когда её перетаскивают на таймлайн дня. Там же видны события Google Calendar и рабочего календаря (Exchange с iPhone). Это тайм-блокинг: день собирается из встреч и задач на одной шкале. Разбора времени из текста задачи нет.

7. **Порядок — ручной.** Задачи не сортируются ни по приоритету, ни по дате: порядок в колонке равен порядку строк в файле и меняется перетаскиванием. Приоритет — только цвет карточки.

8. **Секции живут день.** Внутри списка задачи можно собрать в секции («Morning», «Evening», «Экскурсия»). Секция заводится из меню задачи или сразу пустой, из поля ввода, и исчезает сама, когда из неё унесли последнюю задачу. Это способ убрать с глаз и сгруппировать, а не структура проекта.

9. **Сделанное сразу уходит.** Чекбоксов на экране нет. Done, Won’t do, приоритет, перенос — через меню задачи (тап по карточке). Сделанная задача тут же уезжает в раздел Done файла и пропадает с экрана.

10. **Телефон — главный.** Плагин в первую очередь для iPhone: перетаскивание пальцем, колёсико колонок, полоса над клавиатурой. На Mac то же самое мышью и трекпадом, плюс клавиши и массовые действия.

## Как выглядит день

- **Утро.** Плагин сам перенёс в Now всё, что назначено на сегодня, и вернул в Now вчерашнее несделанное. Открываешь экран «Now и календарь»: слева список дня, справа таймлайн со встречами.
- **Планирование.** Перетаскиваешь задачи из Now на свободные места календаря. Что не влезло — тапом по карточке переносишь на завтра (Tomorrow) или на выбранный день.
- **В течение дня.** Новое быстро пишешь плюсом: в Inbox, если не ясно, что с этим делать; сразу в Now, если это сегодня. Сделал — тап по карточке → Done.
- **Разбор.** Время от времени листаешь колёсико к Inbox и Soon и раскладываешь: из Inbox в Soon или Now, в Backlog — что не скоро, на конкретный день — через меню.
- **Долгий план.** Кнопка с папкой слева сверху — панель проектов. Выбрал проект — весь экран показывает только его задачи, удобнее всего «Строками»: что в Inbox, что в Soon, что ждёт в Backlog. Отсюда решаешь, что брать дальше, и перекладываешь задачу в другой проект, перетащив её на строку дерева. Крестик у имени проекта — снова все задачи.
- **Вечер.** Можно открыть завтрашний день и разложить его задачи по секциям; утром они будут в Now в тех же секциях.

## Файл в двух словах

```markdown
## Inbox
- [ ] Придумать подарок

## Now
- [ ] p1 Позвонить в банк
- [/] Написать отчёт ⏰ 2026-11-05 14:00-15:30
### Evening
- [ ] Полить цветы 📅 2026-11-05 🔁 every 3 days when done

## Soon
- [ ] Купить билеты 📅 2026-11-08
- [ ] Разобрать почту

## Backlog
- [ ] Выучить испанский

## Done
- [x] Сдать анализы
```

- Пять разделов второго уровня: **Inbox** — не разобрано, **Now** — сегодня, **Soon** — не сегодня (без даты или с будущей датой), **Backlog** — когда-нибудь, **Done** — сделанное и отменённое.
- Статусы: `[ ]` открыта, `[/]` в процессе, `[x]` сделана, `[-]` не будет сделана.
- Поля в конце строки: `📅` срок, `⏰` время на календаре, `🔁` повтор. Первое слово `p1`, `p2` — приоритет. Теги `#label/<имя>` — метки: их может быть несколько, вместо приоритета.
- Вложенные задачи — подзадачи; вложенные строки без чекбокса — описание задачи.
- `### Имя` внутри раздела — секция.

Подробно, со всеми правилами, — [Файл задач](file.md).

## Слова

| Слово | Что значит |
|---|---|
| Inbox | Раздел и колонка: задача, про которую ещё непонятно, когда её делать. Без срока и без времени. |
| Backlog | Раздел и нижняя половина первой колонки: сохранено, но не скоро. Без срока и без времени. |
| Soon | Раздел: не сегодня. Колонка Soon показывает только задачи Soon без даты; задачи Soon с датой видны в колонке своего дня. |
| Now | Раздел: сегодня. Колонка дня на сегодня показывает Now. |
| Колонка дня | Список выбранного дня. Сегодня — Now, другой день — задачи с этой датой. |
| Календарь, таймлайн | Шкала выбранного дня: встречи и задачи со временем. |
| Срок, дата, `📅` | День, в который задачу надо сделать. |
| Время, слот, `⏰` | Время на календаре на конкретный день. Ставит плагин, когда задачу кладут на таймлайн. |
| Секция | `### Имя` внутри Inbox, Soon, Now или Backlog — группа задач. |
| Проект, `🗂️` | Имя в разделе `## Projects` файла задач; проекты вкладываются друг в друга на любую глубину. Задача в проекте, если в её строке `🗂️ Имя`; проектов у задачи может быть несколько. Заметка к проекту не обязательна: её можно привязать, тогда ссылка стоит в строке проекта. |
| Панель проектов | Дерево проектов за кнопкой с папкой: выбранный проект фильтрует весь экран. Статус проекта (активный, ждёт, готово) считается сам. |
| Режим вида | Как разложены списки: две колонки, все колонки (Mac), строки, по подпроектам. Кнопка рядом с колёсиком. |
| Подзадача | Задача, вложенная под другую. |
| Описание | Строки без чекбокса под задачей. |
| Колёсико | Переключатель внизу экрана: Inbox, Soon, Now, календарь. |
| Плюс | Круглая кнопка внизу справа: новая задача. |
