# Работа с задачами из агента

Для агента, которому дали доступ к задачам. Плагин — только вид над файлом, поэтому всё делается правкой одного markdown-файла. Сначала прочитай [главную страницу](README.md) и [Файл задач](file.md).

## Где файл

- Волт — `~/Obsidian`, файл — `~/Obsidian/TODOs Tasks.md` (путь — в `~/Obsidian/.obsidian/plugins/task-calendar/data.json`, ключ `tasksFile`; там же имена разделов `sections`, эмодзи и начало дня `dayStartHour`).
- Файл синхронизируется с телефоном через Obsidian Sync. Правка на Mac появится на iPhone через несколько секунд.
- Встречи — `~/Obsidian/calendar/work.json` (рабочие, его перезаписывает телефон) и `~/Obsidian/calendar/google.json` (Google, его перезаписывает плагин). Оба только для чтения.
- `data.json` содержит токен Google: не выводи его и никуда не отправляй.

## Как читать

- «Что у меня сегодня» — раздел Now плюс задачи Soon со сроком или временем на сегодня (обычно плагин их уже перенёс в Now). Задачи с `⏰` на сегодня — план по времени, их удобно перечислить по порядку времени.
- «Что на завтра / на дату D» — задачи Now и Soon с `📅 D` или `⏰ D …`.
- «Что во входящих» — Inbox. «Когда-нибудь» — Backlog.
- Done — история; новые сверху.
- «Сегодня» считается от начала дня (`dayStartHour`, обычно 5): в 2 часа ночи сегодня — ещё вчерашнее число.
- Подзадачи и описание — вложенные строки под задачей. Отвечая про задачу, учитывай их.

## Как править

Главное правило: **пиши строку в том виде, в каком её написал бы плагин, и клади её туда, куда её положил бы плагин**. Тогда плагин ничего не будет переделывать.

| Просьба | Что сделать в файле |
|---|---|
| Добавь задачу (без уточнений) | `- [ ] Текст` в конец Inbox |
| Добавь на сегодня | `- [ ] Текст 📅 <сегодня>` в конец Now |
| Добавь на дату D (в будущем) | `- [ ] Текст 📅 D` в конец Soon |
| Добавь «когда-нибудь» | `- [ ] Текст` в конец Backlog |
| Добавь на время | `- [ ] Текст 📌 D HH:MM-HH:MM` (или `📌 D HH:MM`), как пишет сам плагин; в Now, если D сегодня, иначе в Soon |
| Отметь сделанной | поменяй `[ ]` на `[x]` — плагин сам унесёт её в Done (и создаст копию, если есть `🔁`) |
| Отмени | `[-]` |
| Перенеси на завтра | поставь `📅 <завтра>`, убери время (`⏰`, `📌`, `🚨` или `🔕` с датой и часами), перенеси строку со всем вложенным в конец Soon |
| Приоритет | первое слово `p1` / `p2` (уровни — в `priorities` в `data.json`, по умолчанию `p1`, `p2`) |
| Подзадача | строка `- [ ] …` под задачей с отступом на таб глубже |
| Заметка к задаче | строка `- …` без чекбокса под задачей с отступом на таб глубже |
| Повтор | поле `🔁 every …` по грамматике из [Файл задач → Повтор](file.md#повтор) |

Даты — `YYYY-MM-DD`, время — `HH:MM` в 24 часа. Поля через пробел в конце строки.

## Чего не делать

- **Не заводи свою структуру.** Только пять разделов `##`, секции `###` внутри Inbox, Now, Soon, Backlog. Свои заголовки, таблицы, теги-статусы плагин не понимает (текст он сохранит, но на экране это будет мусор).
- **Не ставь просрочку и не копи прошлое.** Не пиши даты в прошлом и не помечай «просрочено»: прошедшее плагин сам переводит на сегодня.
- **Не сортируй** задачи по приоритету или дате: порядок ручной, это порядок Макса.
- **Не трогай** строки, которые не просили менять: плагин бережёт файл байт в байт.
- **Пустая секция — можно**, если Макс просил её завести: `### Имя` без задач плагин держит и показывает плашкой «No tasks». Не заводи пустые секции сам и не оставляй заголовок, из которого унёс все задачи: убери его.
- **Не разрывай задачу пустой строкой**: пустая строка кончает задачу, её подзадачи и описание отвалятся.
- **Не клади в Inbox и Backlog задачи со сроком или временем** — плагин сразу унесёт их в Soon или Now.
- **Не переноси сделанное в Done сам** — достаточно `[x]`.
- **Не добавляй время, которого не просили.** Время — это план Макса на календаре, его ставят перетаскиванием.
- Править файл через `obsidian` CLI или прямо на диске — одинаково: плагин заметит изменение. Если в этот момент Макс что-то делает в плагине с той же задачей, его действие отменится с уведомлением — это нормально.
