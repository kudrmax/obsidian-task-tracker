# Работа с задачами из агента

Для агента, которому дали доступ к задачам. Плагин — только вид над файлом. **Читать** задачи — программой `obsidian-task-calendar`, она отвечает так, как задачи видит Макс. **Править** — одним markdown-файлом, по рецептам ниже. Сначала прочитай [главную страницу](README.md) и [Файл задач](file.md).

## Где файл

- Волт — `~/Obsidian`, файл — `~/Obsidian/TODOs Tasks.md` (путь — в `~/Obsidian/.obsidian/plugins/task-calendar/data.json`, ключ `tasksFile`; там же имена разделов `sections`, эмодзи и начало дня `dayStartHour`).
- Файл синхронизируется с телефоном через Obsidian Sync. Правка на Mac появится на iPhone через несколько секунд.
- Встречи — `~/Obsidian/calendar/google.json` (Google, пишет плагин), `~/Obsidian/calendar/iphone.json` (календари iPhone, пишет приложение) и `~/Obsidian/calendar/work.json` (Scriptable, запасной). Все только для чтения; какой календарь из какого файла берётся — [Календари](calendars.md).
- `data.json` содержит токен Google: не выводи его и никуда не отправляй.

## Как читать

**Читай программой, а не файлом.** `node .claude/skills/obsidian-task-calendar/obsidian-task-calendar.mjs <команда>` из корня волта (программа лежит в самом волте рядом со скиллом `obsidian-task-calendar`, только читает, файл и настройки не трогает) отвечает одним JSON-объектом словами экрана. Она считает ответ тем же ядром, что плагин и приложение на iPhone, поэтому видит задачи так же, как Макс: какие задачи сегодня, что в колонке Soon, какой шаг показывает свёрнутая задача, на каком дне стоит слот после полуночи. Разбирать `TODOs Tasks.md`, чтобы прочитать задачи, не надо: раздел файла и место на экране различаются, и по файлу легко ошибиться.

| Вопрос | Команда |
|---|---|
| «Что у меня сегодня», «разбери мой день» | `today`: список дня по секциям, календарь дня (задачи со временем) и встречи |
| «Что на завтра / на дату D» | `day tomorrow`, `day 2026-11-20`, `day +3`, `day -1` |
| «Что на неделе», «что на следующей неделе» | `week`, `week this`, `week next` (с понедельника по воскресенье, без `--days`), `week 2026-11-20 --days 3` |
| «Что во входящих», «что в Soon», «что когда-нибудь» | `inbox`, `soon`, `backlog`: колонка по секциям, пустые секции тоже |
| «Все мои задачи» | `all`: каждая открытая задача один раз, по порядку ленты |
| «Какие у меня проекты» | `projects`: всё дерево, папки, статус, заметка |
| «Что по проекту X» | `project X`: как экран By project — свои задачи, потом подпроекты; внутри Inbox, Backlog, Soon (с датированными), Now. `--no-subprojects` — без подпроектов, `--done` — с сделанными |
| «Найди задачу про …» | `search <текст>`: поиск плагина, Done тоже |
| Одна задача целиком | `task <ref>`: описание, все подзадачи, где она лежит в файле |

- `--project <имя>` у `today`, `day`, `week`, `soon`, `inbox`, `backlog`, `all` — фильтр по проекту, как выбранный в панели (с подпроектами; `--no-subprojects` — без них). `--no-project` — задачи без проекта. Неизвестное имя — ошибка `unknownProject` с ближайшими именами.
- `--pretty` — JSON с отступами. `help` — все команды, слова, приоритеты и метки Макса.
- Ошибка — `{ "error": { "code", "message" } }` и код выхода 1. `tasksFileMissing` — нет файла задач.

**Где задача — поле `place`**, а не раздел файла:

| `place` | Как сказать Максу |
|---|---|
| `inbox` | во входящих (Inbox) |
| `backlog` | в Backlog, когда-нибудь |
| `soon` | в Soon: без даты |
| `today` | сегодня (в файле — Now) |
| `day` + `date` | на этот день: Макс видит задачу только в колонке её дня, не в Soon. Говори «на четверг», а не «в Soon» |
| `done` | сделано (в `search`, `task`, `project --done`) |

- `date` — день, на котором стоит задача: день её слота, иначе сегодня для Now, иначе срок; `due` — срок, только если он другой. Дата — план, не дедлайн: просроченного нет.
- Задача со сроком и слотом на другой день видна в обоих днях, как на экране: в списке дня срока и в календаре дня слота (`date` в обоих — день слота). Поэтому `week` покажет её дважды.
- `time.startsAt` — полный момент слота: день идёт от начала дня (`dayStart`, обычно 5:00) до 5:00 следующего утра, так что слот в 00:30 относится к предыдущему вечеру. `time.passed` — задача уже на линии «сейчас».
- Свёрнутая задача (`collapsed`) — на карточке и на календаре её следующий шаг `nextStep`, название задачи мелко над ним; Done закрывает шаг. `subtasks` — все открытые подзадачи, шаг помечен `next`.
- Прошедший день — `past: true`, список и календарь пустые: что не сделано, плагин перенёс на сегодня, а дату сделанного файл не хранит.
- `ref` — только для `task <ref>`. После любой правки файла или смены дня ref устаревают (`staleTask`): прочитай заново.
- Строка `- Контекст: …` в описании — то, что Макс сам написал о задаче (часто после того, как ассистент её неверно оценил). Это правда о задаче: верь ей больше, чем догадке по названию.
- `task <ref>` в поле `stored` даёт раздел и строку файла такими, какие они на диске сейчас: это только чтобы править по рецептам ниже, Максу так не говори. `pending: true` — этой строки в файле ещё нет (её допишет Obsidian, когда сегодня откроет файл): прочитай позже.

**Файл для правки.** Чтобы поправить задачу, найди её строку в файле (`stored` из `task <ref>` подскажет раздел и текст). Как устроен файл:

- Подзадачи и описание — вложенные строки под задачей.
- Done — история, новые сверху.
- «Сегодня» считается от начала дня (`dayStartHour`, обычно 5): в 2 часа ночи сегодня — ещё вчерашнее число.
- Проекты — раздел `## Projects`: вложенный список имён, отступ — подпроект. `[[…]]` после имени — привязанная заметка проекта. Задача в проекте — `🗂️ Имя` в её строке, проектов может быть несколько.
- `🗃️` после имени в строке `## Projects` (`- Работа 🗃️`, перед `[[заметкой]]`) — **папка**: проект, который только держит подпроекты. Папке задачи не дают.
- Статус проекта не пишется, его считают (живой, ждёт, готово); программа отдаёт его в `projects`.

## Как править

Главное правило: **пиши строку в том виде, в каком её написал бы плагин, и клади её туда, куда её положил бы плагин**. Тогда плагин ничего не будет переделывать.

| Просьба | Что сделать в файле |
|---|---|
| Добавь задачу (без уточнений) | `- [ ] Текст` в конец Inbox |
| Добавь на сегодня | `- [ ] Текст 📅 <сегодня>` в конец Now |
| Добавь на дату D (в будущем) | `- [ ] Текст 📅 D` в конец Soon |
| Добавь «когда-нибудь» | `- [ ] Текст` в конец Backlog |
| Добавь на время | `- [ ] Текст 📌 D HH:MM-HH:MM` (или `📌 D HH:MM`), как пишет сам плагин; в Now, если D сегодня, иначе в Soon |
| Отметь сделанной | поменяй `[ ]` на `[x]` — плагин сам унесёт её в Done (и создаст копию, если есть `🔁`) |
| Отмени | `[-]` |
| Перенеси на завтра | поставь `📅 <завтра>`, убери время (`⏰`, `📌`, `🚨` или `🔕` с датой и часами), перенеси строку со всем вложенным в конец Soon |
| Приоритет | первое слово `p1` / `p2` (уровни — в `priorities` в `data.json`, по умолчанию `p1`, `p2`) |
| Метка | тег `#label/<имя>` после текста, до полей; имена и цвета — в `labels` в `data.json` (цвет `"clear"` — метка без цвета, карточку не красит), папка тега — `labelTag`. Не ставь метку задаче с приоритетом и наоборот |
| Подзадача | строка `- [ ] …` под задачей с отступом на таб глубже |
| Заметка к задаче | строка `- …` без чекбокса под задачей с отступом на таб глубже |
| Запомни про задачу (что Макс знает о ней, а по названию не видно) | `- Контекст: <текст>` одной строкой последним пунктом описания: под задачей с отступом на таб глубже, после её строк описания и перед подзадачами. Уже есть такие строки — новую в конец, старые не трогай |
| Повтор | поле `🔁 every …` по грамматике из [Файл задач → Повтор](file.md#повтор); у N > 1 пиши `from YYYY-MM-DD` (без него правило считается от срока задачи, а у задачи без срока остаётся текстом) |
| Отнеси к проекту | поле `🗂️ Имя проекта` сразу после текста, перед метками, `📁` и сроком; ещё один проект — ещё одно `🗂️ Имя`. Строку не двигай: задача остаётся на своём месте в ленте. Подзадаче не ставь — у неё проекты родителя. Имя — ровно как в `## Projects`, без `[[ ]]` |
| Перенеси в другой проект | замени имя в `🗂️` на новое на том же месте; если новый уже есть — просто сотри старый. Остальные `🗂️` строки не трогай |
| Убери из проекта | сотри `🗂️ Имя` со строки |
| Добавь шаг в проект X | `- [ ] Текст 🗂️ X` в конец Inbox (или куда просят: Backlog, Soon, Now со сроком) |
| Заведи проект | строка `- Имя` в `## Projects`: в конец списка или под родителем с отступом на таб глубже (подпроект). Имя не должно повторять другой проект. Если раздела нет — `## Projects` сразу после Inbox |
| Переименуй проект | имя в его строке `## Projects` и во всех `🗂️ Старое имя` файла. Заметку не трогай |
| Удали проект | сотри его строку в `## Projects` (подпроекты подними на уровень вверх, на его место) и `🗂️ Имя` со всех строк файла. Задачи не удаляй, не закрывай и не переноси. Заметку не трогай |
| Отнеси к проекту-папке | нельзя: у папки (`🗃️` в её строке) задач не бывает. Спроси, в какой из её подпроектов, или заведи подпроект |
| Сделай проект папкой | `🗃️` сразу после имени в его строке `## Projects`: `- Работа 🗃️` (перед `[[заметкой]]`, если есть). Только если ни одна строка файла не несёт `🗂️ Имя` этого проекта; иначе сначала перенеси эти задачи в подпроекты |
| Сделай папку снова проектом | сотри `🗃️` из её строки |
| Привяжи заметку к проекту | `[[Имя заметки]]` в конец строки проекта в `## Projects`: `- Дружба [[Моя заметка о дружбе]]` |
| Покажи следующий шаг задачи | у задачи с подзадачами поставь `📁`: свёрнутая карточка показывает её первую открытую подзадачу |
| Сверни / разверни подзадачи | поставь `📁` после текста и меток, перед сроком; убери, чтобы развернуть. Только задаче с открытой подзадачей, иначе плагин сам его сотрёт |

Даты — `YYYY-MM-DD`, время — `HH:MM` в 24 часа. Поля через пробел в конце строки.

## Чего не делать

- **Не заводи свою структуру.** Только пять разделов `##` и `## Projects`, секции `###` внутри Inbox, Now, Soon, Backlog. В `## Projects` — только пункты списка с именами (знаком папки `🗃️` и ссылкой на заметку), без `[ ]`. Свои заголовки, таблицы, теги-статусы плагин не понимает (текст он сохранит, но на экране это будет мусор).
- **Не ставь просрочку и не копи прошлое.** Не пиши даты в прошлом и не помечай «просрочено»: прошедшее плагин сам переводит на сегодня.
- **Не сортируй** задачи по приоритету или дате: порядок ручной, это порядок Макса.
- **Не трогай** строки, которые не просили менять: плагин бережёт файл байт в байт.
- **Пустая секция — можно**, если Макс просил её завести: `### Имя` без задач плагин держит и показывает одним заголовком. Не заводи пустые секции сам и не оставляй заголовок, из которого унёс все задачи: убери его.
- **Не пиши задачи в заметку проекта.** Все задачи — в файле задач; заметка проекта — для мыслей, плагин в неё ничего не пишет.
- **Не пиши `🎯`.** Результатов больше нет: задача из нескольких шагов — просто задача с подзадачами (свёрнутая показывает следующий шаг) или подпроект.
- **Не путай `📁`, `🗂️` и `🗃️`**: `📁` — свёрнутые подзадачи, `🗂️` — проект задачи, `🗃️` — папка в `## Projects`.
- **Не ставь `🗂️ Папка`** на задачу: папка задач не берёт.
- **Не разрывай задачу пустой строкой**: пустая строка кончает задачу, её подзадачи и описание отвалятся.
- **Не клади в Inbox и Backlog задачи со сроком или временем** — плагин сразу унесёт их в Soon или Now.
- **Не переноси сделанное в Done сам** — достаточно `[x]`.
- **Не добавляй время, которого не просили.** Время — это план Макса на календаре, его ставят перетаскиванием.
- Править файл через `obsidian` CLI или прямо на диске — одинаково: плагин заметит изменение. Если в этот момент Макс что-то делает в плагине с той же задачей, его действие отменится с уведомлением — это нормально.
