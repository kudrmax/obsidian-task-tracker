# Рабочий календарь на iPhone

Главный путь рабочего календаря теперь — приложение Tasks на iPhone: оно само пишет календари телефона в `calendar/iphone.json` ([Календари](calendars.md)). Scriptable остаётся запасным: его файл берётся, когда файл приложения устарел (например, истекла 7-дневная подпись). Настраивать его стоит, чтобы запасной путь работал.

Плагин не умеет сам читать календари iPhone (Exchange и остальные аккаунты). Их выгружает Scriptable: события всех календарей телефона со вчера по две недели вперёд, без встреч, от которых ты отказался, в файл `calendar/work.json` в волте. Плагин читает этот файл (Settings → Task Calendar → More → Calendars → Work calendar → File path).

Как это устроено:

- **Выгрузка** лежит в папке плагина: `.obsidian/plugins/task-calendar/work-calendar-export.js`. Её кладёт сам плагин и обновляет с каждым релизом, руками её не трогают.
- **Скрипт в Scriptable** `Export Work Calendar` — короткий запускающий скрипт: он находит волт и запускает выгрузку. Вставляется один раз.
- **Команда** `Export Work Calendar` в «Командах» запускает этот скрипт в фоне. Её запускают автоматизации и кнопка «Refresh now» в плагине.

Настраивается один раз, на iPhone, в три части.

## Часть 1. Scriptable

1. На iPhone открой Obsidian → Settings → Task Calendar → More → Calendars → Scriptable script → **Copy**.
2. Открой Scriptable. Если скрипта `Export Work Calendar` ещё нет, создай его кнопкой **+**. Удали в нём весь старый текст, вставь скопированный, нажми **Done**. Имя скрипта должно быть ровно `Export Work Calendar`.
3. Scriptable → шестерёнка → **File Bookmarks** → **+** → выбери папку волта (та, где лежат заметки и папка `calendar`) → имя `ObsidianVault`. Если такая закладка уже есть, просто проверь, что она ведёт на папку волта.
4. Нажми на скрипт в Scriptable, чтобы запустить его один раз. iOS попросит доступ к календарям, разреши. Должно появиться окно «Экспорт готов, N событий → calendar/work.json».

## Часть 2. Команда

Закладка из настроек Scriptable работает только тогда, когда скрипт запускается внутри Scriptable. Когда скрипт запускают «Команды» в фоне, она недоступна. Поэтому команда сначала сама создаёт закладку на папку волта и только потом запускает скрипт.

5. «Команды» → All Shortcuts → **+** справа вверху.
6. Нажми на название вверху → Rename → `Export Work Calendar`.
7. В поиске действий набери **File** и выбери действие, которое называется ровно «File» (синяя иконка, описание «Passes the specified files or folders as output»). Не Get File, не Select File, не Open File.
8. В этом действии нажми на синее слово «File» → Browse → On My iPhone → Obsidian → зайди внутрь папки волта → **Open** справа вверху. В действии должно появиться имя папки волта.
9. Добавь действие Scriptable **Create File Bookmark**. Нажми на поле файла и выбери над клавиатурой плашку **File** (результат шага 8). В поле Name впиши `ObsidianVault`.
10. Добавь действие Scriptable **Run Script**. В поле Script выбери `Export Work Calendar`. Раскрой стрелку с параметрами и выключи **Run In App**.
11. Нажми **Done**. Для проверки нажми на плитку команды: она отработает молча, без окон.

## Часть 3. Автоматизации

12. Вкладка **Automation** → **+** → **App** → выбери Obsidian, отметь **Is Opened**, выбери **Run Immediately**, выключи **Notify When Run** → Next → выбери команду `Export Work Calendar`. События обновляются каждый раз, когда открываешь Obsidian.
13. Снова **+** → **Time of Day** → 09:00, **Daily**, **Run Immediately** → Next → `Export Work Calendar`. Повтори для каждого часа, в который нужно обновление, например 10:00, 11:00 и дальше до 19:00. «Каждый час» iOS не умеет, поэтому по автоматизации на час.

Если рабочие встречи есть и в каком-то календаре Google, выключи один из двух в Settings → Task Calendar → More → Calendars → **Calendars shown**: иначе встречи покажутся дважды.

## Обновить вручную

В плагине открой календарь и долго нажми на переключатель внизу: откроется окно источников. Кнопка **Refresh now** сначала открывает приложение Tasks. Команду Scriptable она запускает, только если подпись приложения истекла или приложение ничего не записало: тогда на мгновение появляются «Команды» и сразу возвращают в Obsidian.

Потягиванием таймлайна вниз обновить нельзя: iOS разрешает плагину открыть «Команды» только в ответ на тап, а не на перетаскивание пальцем, поэтому этот жест убран.

## Как проверить, что работает

1. Открой окно источников (долгое нажатие на переключатель, когда открыт календарь). В строке **Work calendar** подпись «Exported from iPhone» и справа время последней выгрузки. Запомни его.
2. Нажми **Refresh now** или плитку команды в «Командах».
3. Снова открой окно источников. Время должно смениться на текущее.

Сами встречи для проверки менять не нужно: время выгрузки обновляется при каждом запуске.

## Если не работает

| Что видно | Что не так |
|---|---|
| «Команды» пишут «Could not find the shortcut "Export Work Calendar"» | Команда не создана или называется иначе (часть 2, шаг 6). |
| Время в окне источников не меняется после плитки команды | Запусти скрипт прямо в Scriptable (шаг 4): если там ошибка, она покажется. |
| Scriptable: «Нет файловой закладки "ObsidianVault"» | В Scriptable — нет закладки из шага 3. В команде — шаг 9 не получил папку из шага 8. |
| Scriptable: «Нет .obsidian/plugins/task-calendar/work-calendar-export.js» | Плагин на этом iPhone ещё не запускался: открой Obsidian с плагином и запусти снова. |
| Оранжевая точка на кнопке календаря | Выгрузки не было дольше, чем указано в настройках (по умолчанию 3 часа), или файл не читается: подробности в окне источников. |

## На Mac

Mac рабочие события не выгружает: он получает тот же `calendar/work.json` с телефона через Obsidian Sync. Sync переносит этот файл, только если в его настройках включены «другие типы файлов» (Settings → Sync → Other types); иначе на Mac рабочих событий нет.
