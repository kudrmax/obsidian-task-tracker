# Быстрый ввод с iPhone

Задачу можно записать, не открывая Obsidian: текстом, голосом или и тем и другим. Это делает приложение Tasks для iPhone (то же, что ставит [напоминания](notifications.md)). Приложение пишет прямо в файл задач, Obsidian не открывается: задача встаёт в конец выбранного раздела, как при вводе в плагине (правила формата приложение берёт из того же модуля, по которому читает напоминания). Sync привезёт её на Mac.

## Экран новой задачи

В приложении две вкладки в нижней панели: **New Task** (открывается сразу) и **Settings** (папка волта, разрешения, будильники, тег записи).

- Сверху переключатель **Inbox / Now / Soon / Backlog**. По умолчанию Inbox. Задача в Now получает сегодняшний срок, в остальных — без срока.
- Поле **New task** — текст задачи. Клавиатура открывается тапом по полю или по любому пустому месту под ним, сама при открытии вкладки не выскакивает. Смахивание вниз её убирает. Несколько строк склеиваются в одну через пробел.
- Внизу красная кнопка микрофона: над вкладками, а пока открыта клавиатура — над клавиатурой. Во время записи на её месте корзина (выбросить запись), время со словом Recording или Paused, **пауза** (продолжить — кнопка с микрофоном) и **стоп**. После стопа там Voice note с длительностью и корзина.
- **Add** (галочка справа сверху) записывает задачу; если запись ещё идёт, она сначала останавливается. Экран очищается для следующей задачи, под полем видно «Added to <список>». Крестик слева сверху (виден, когда есть текст или запись) очищает черновик.

Запись — обычный файл `Recording ГГГГММДДччммсс.m4a`, как у диктофона Obsidian. Он кладётся туда, куда Obsidian кладёт вложения (Settings → Files and links → Default location for new attachments), а в строку задачи пишется ссылка на него и тег для расшифровки:

```markdown
## Inbox
- [ ] Позвонить в банк
- [ ] [[Recording 20261106143200.m4a]] #transcribe
- [ ] Идея для поездки [[Recording 20261106151000.m4a]] #transcribe
```

Если есть и текст, и запись, текст идёт первым. Тег ставится только задаче с записью. Он задаётся в приложении: **Recording Tag**, по умолчанию `#transcribe`; пустое поле — без тега.

## Откуда открыть

Экран новой задачи один, откуда его ни открой: печатать или записывать, решаешь уже на нём.

- **Виджет на экране блокировки.** Долгое нажатие на экран блокировки → **Customize** → **Lock Screen** → тап по полосе виджетов под часами → в списке приложений **Tasks** → круглый **New Task**. Тап по нему после Face ID открывает вкладку New Task.
- **Кнопка в нижнем углу экрана блокировки** (вместо фонарика или камеры) и **Пункт управления**: там же, **+** → Tasks → **New Task**.
- **Кнопка действия** (iPhone 15 Pro и новее): Settings → Action Button → **Shortcut** → Tasks → **New Task**.
- **Siri** (по-английски): «Hey Siri, add a task to Tasks» → Siri спрашивает «What's the task?» → диктуешь название → «Added to Inbox.», приложение не открывается. Годятся и «Add a task in Tasks», «Add task to Tasks», «Add task in Tasks», «New task in Tasks»; похожие формулировки iOS тоже старается понять. Имя приложения во фразе обязательно, а сказать название задачи той же фразой («add buy milk to Tasks») нельзя: так умеют только приложения с платной подписью Apple Developer Program.
- **Своя команда «Add a task»** — чтобы говорить Siri без имени приложения. Один раз в приложении «Команды» (Shortcuts): **+** → **Add Action** → найди **Tasks** → **Add Task** → тап по синему полю **Task** → **Ask Each Time** → вверху тап по имени команды → **Rename** → `Add a task` → **Done**. Потом «Hey Siri, add a task» → «What's the task?» → название → задача в Inbox.
- **Команды**: действия **New Task** (открыть экран) и **Add Task** (текст в Inbox) можно ставить и в другие свои команды.
- В самом приложении — вкладка **New Task**.

## Если не записалось

Ошибка видна красной строкой на экране новой задачи (Siri её произносит): нет доступа к папке волта — выбери её в приложении заново; нет файла задач — проверь Tasks file в настройках плагина. Текст и запись при этом остаются на экране, можно нажать Add ещё раз. Без разрешения на микрофон кнопка записи пишет, что его надо включить в Настройках.

## Проверка

1. Поставь на экран блокировки виджет **New Task** (см. выше). Заблокируй телефон, тапни виджет: после Face ID открылась вкладка New Task, Inbox выбран, клавиатуры нет.
2. Нажми микрофон, скажи пару слов, нажми паузу, потом снова микрофон, ещё пару слов, **Add**.
3. Открой Obsidian на iPhone: в конце Inbox задача `[[Recording …m4a]] #transcribe`; по ссылке запись играет целиком, с обоими кусками.
4. В приложении вкладка **New Task** → переключи на **Now** → тап по полю → напиши «Проверка» → Add. В Obsidian задача в конце Now с сегодняшней датой.
5. «Hey Siri, add a task to Tasks» → «Buy milk». В Inbox появилась `Buy milk`.
6. «Hey Siri, add a task» (своя команда) → «Call mom». В Inbox появилась `Call mom`.
