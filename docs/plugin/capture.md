# Быстрый ввод с iPhone

Задачу можно записать, не открывая Obsidian: текстом, голосом или и тем и другим. Это делает приложение Task Calendar для iPhone (то же, что ставит [напоминания](notifications.md)). Задача встаёт в конец **Inbox** или **Now** файла задач по тем же правилам, что и ввод в плагине; Sync привезёт её на Mac.

## Экран новой задачи

- Сверху переключатель **Inbox / Now**. По умолчанию Inbox. Задача в Now получает сегодняшний срок.
- Поле **New task** — текст задачи. Несколько строк склеиваются в одну через пробел.
- Внизу красная кнопка микрофона. Во время записи видно время, **пауза** (продолжить — та же кнопка с микрофоном), **стоп** и корзина (выбросить запись). После стопа запись видна плашкой Voice note с длительностью.
- **Add** (галочка справа сверху) записывает задачу; если запись ещё идёт, она сначала останавливается. **Cancel** закрывает экран и выбрасывает запись.

Запись — обычный файл `Recording ГГГГММДДччммсс.m4a`, как у диктофона Obsidian. Он кладётся туда, куда Obsidian кладёт вложения (Settings → Files and links → Default location for new attachments), а в описание задачи пишется его встраивание:

```markdown
## Inbox
- [ ] Позвонить в банк
- [ ] Voice note 14:32
	![[Recording 20261106143200.m4a]]
```

Без текста задача называется `Voice note ЧЧ:ММ`. Запись слушается в описании задачи, плеером Obsidian.

## Откуда открыть

- **Кнопка на экране блокировки.** Долгое нажатие на экран блокировки → **Настроить** → **Экран блокировки** → тап по кнопке внизу (фонарик или камера) → убрать её → **+** → найти Task Calendar → **New Task** (откроет ввод текста) или **Voice Task** (запись начнётся сразу). Телефон попросит Face ID и откроет экран новой задачи.
- **Пункт управления.** Так же: Пункт управления → **+** → **Добавить элемент** → Task Calendar.
- **Кнопка действия** (iPhone 15 Pro и новее): Настройки → Кнопка действия → **Команда** → Task Calendar → New Task или Voice Task.
- **Siri** (по-английски: Siri не знает русского):
  - «Add a task in Task Calendar» — Siri спросит текст и запишет задачу в Inbox, приложение не откроется. «Add a task to Now in Task Calendar» — то же в Now.
  - «New task in Task Calendar» — откроет экран новой задачи.
  - «Record a task in Task Calendar» — откроет экран с уже идущей записью.
- **Команды**: действия **Add Task** (текст и список) и **New Task** (список и «Start Recording») можно ставить в свои команды.
- В самом приложении — **+** справа сверху.

## Если не записалось

Ошибка видна красной строкой на экране новой задачи (Siri её произносит): нет доступа к папке волта — выбери её в приложении заново; нет файла задач — проверь Tasks file в настройках плагина. Текст и запись при этом остаются на экране, можно нажать Add ещё раз. Без разрешения на микрофон кнопка записи пишет, что его надо включить в Настройках.

## Проверка

1. На iPhone поставь на экран блокировки кнопку **Voice Task** (см. выше). Заблокируй телефон, нажми кнопку: после Face ID открылся экран новой задачи и идёт запись.
2. Скажи пару слов, нажми паузу, потом снова микрофон, ещё пару слов, **Add**.
3. Открой Obsidian на iPhone: в конце Inbox задача `Voice note …`, в её описании плеер, запись играет целиком, с обоими кусками.
4. В приложении **+** → переключи на **Now** → напиши «Проверка» → Add. В Obsidian задача в конце Now с сегодняшней датой.
5. «Hey Siri, add a task in Task Calendar» → «Buy milk». В Inbox появилась `Buy milk`.
