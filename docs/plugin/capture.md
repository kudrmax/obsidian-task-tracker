# Быстрый ввод с iPhone

Задачу можно записать, не открывая Obsidian: текстом, голосом или и тем и другим. Это делает приложение Task Calendar для iPhone (то же, что ставит [напоминания](notifications.md)). Приложение пишет прямо в файл задач, Obsidian не открывается: задача встаёт в конец выбранного раздела, как при вводе в плагине (правила формата приложение берёт из того же модуля, по которому читает напоминания). Sync привезёт её на Mac.

## Экран новой задачи

- Сверху переключатель **Inbox / Now / Soon / Backlog**. По умолчанию Inbox. Задача в Now получает сегодняшний срок, в остальных — без срока.
- Поле **New task** — текст задачи. Несколько строк склеиваются в одну через пробел.
- Внизу красная кнопка микрофона. Во время записи видно время, **пауза** (продолжить — та же кнопка с микрофоном), **стоп** и корзина (выбросить запись). После стопа запись видна плашкой Voice note с длительностью.
- **Add** (галочка справа сверху) записывает задачу; если запись ещё идёт, она сначала останавливается. **Cancel** закрывает экран и выбрасывает запись.

Запись — обычный файл `Recording ГГГГММДДччммсс.m4a`, как у диктофона Obsidian. Он кладётся туда, куда Obsidian кладёт вложения (Settings → Files and links → Default location for new attachments), а в строку задачи пишется ссылка на него и тег для расшифровки:

```markdown
## Inbox
- [ ] Позвонить в банк
- [ ] [[Recording 20261106143200.m4a]] #transcribe
- [ ] Идея для поездки [[Recording 20261106151000.m4a]] #transcribe
```

Если есть и текст, и запись, текст идёт первым. Тег ставится только задаче с записью. Он задаётся в приложении: **Recording Tag**, по умолчанию `#transcribe`; пустое поле — без тега.

## Откуда открыть

Экран новой задачи один, откуда его ни открой: печатать или записывать, решаешь уже на нём.

- **Виджет на экране блокировки.** Долгое нажатие на экран блокировки → **Customize** → **Lock Screen** → тап по полосе виджетов под часами → в списке приложений **Task Calendar** → круглый **New Task**. Тап по нему после Face ID открывает экран новой задачи.
- **Кнопка в нижнем углу экрана блокировки** (вместо фонарика или камеры) и **Пункт управления**: там же, **+** → Task Calendar → **New Task**.
- **Кнопка действия** (iPhone 15 Pro и новее): Settings → Action Button → **Shortcut** → Task Calendar → **New Task**.
- **Siri** (по-английски: Siri не знает русского): «Add a task in Task Calendar» → Siri спрашивает «What's the task?» → диктуешь название → задача в конце Inbox, приложение не открывается. Имя приложения в фразе обязательно: так iOS понимает, какому приложению она адресована.
- **Команды**: действия **New Task** (открыть экран) и **Add Task** (текст в Inbox) можно ставить в свои команды.
- В самом приложении — **+** справа сверху.

## Если не записалось

Ошибка видна красной строкой на экране новой задачи (Siri её произносит): нет доступа к папке волта — выбери её в приложении заново; нет файла задач — проверь Tasks file в настройках плагина. Текст и запись при этом остаются на экране, можно нажать Add ещё раз. Без разрешения на микрофон кнопка записи пишет, что его надо включить в Настройках.

## Проверка

1. Поставь на экран блокировки виджет **New Task** (см. выше). Заблокируй телефон, тапни виджет: после Face ID открылся экран новой задачи, Inbox выбран.
2. Нажми микрофон, скажи пару слов, нажми паузу, потом снова микрофон, ещё пару слов, **Add**.
3. Открой Obsidian на iPhone: в конце Inbox задача `[[Recording …m4a]] #transcribe`; по ссылке запись играет целиком, с обоими кусками.
4. В приложении **+** → переключи на **Now** → напиши «Проверка» → Add. В Obsidian задача в конце Now с сегодняшней датой.
5. «Hey Siri, add a task in Task Calendar» → «Buy milk». В Inbox появилась `Buy milk`.
