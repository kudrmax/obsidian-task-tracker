# Быстрый ввод с iPhone

Задачу можно записать, не открывая Obsidian: текстом, голосом или и тем и другим. Это делает приложение Tasks для iPhone (то же, что ставит [напоминания](notifications.md)). Приложение пишет прямо в файл задач, Obsidian не открывается: задача встаёт в конец выбранного раздела, как при вводе в плагине (правила формата приложение берёт из того же модуля, по которому читает напоминания). Sync привезёт её на Mac.

## Экран новой задачи

Экран новой задачи открывается круглым **+** справа от таб-бара на [главном экране приложения](app.md) и поднимается листом поверх него; смахивание вниз его закрывает. Открытый плюсом, экран поднимается сразу с клавиатурой и курсором в поле: можно сразу печатать, микрофон в одном тапе. Настройки приложения (папка волта, разрешения, будильники, тег записи) — в **⋯ → Settings**.

- Сверху переключатель разделов: Inbox, Now, Soon, Backlog, в этом порядке, каждый под тем именем, что у его заголовка в файле (Settings плагина → Sections). Переименовал `## Inbox` в `## Входящие` — на переключателе «Входящие»; имена перечитываются, когда возвращаешься в приложение. По умолчанию первый, Inbox. Задача в Now получает сегодняшний срок, в остальных — без срока.
- Под переключателем строка **Project** — меню со всем деревом проектов (подпроект с именем родителя мелко под своим), «No project» и «New project…» (спрашивает имя и создаёт проект вверху дерева `## Projects`, как в плагине). Здесь выбирается один проект. Открытый плюсом на вкладке Projects, экран начинает с выбранным там проектом. Задача пишется с `🗂️ Проект` в конец выбранного раздела.
- Поле **New task** — текст задачи. Открытый с виджета на экране блокировки, экран появляется без клавиатуры (сначала обычно выбирают раздел или голос): клавиатура открывается тапом по полю или по любому пустому месту под ним. Смахивание вниз её убирает. Несколько строк склеиваются в одну через пробел.
- Внизу красная кнопка микрофона, а пока открыта клавиатура — над клавиатурой. Во время записи на её месте корзина (выбросить запись), время со словом Recording или Paused, **пауза** (продолжить — кнопка с микрофоном) и **стоп**. После стопа там Voice note с длительностью и корзина.
- **Add** (галочка справа сверху) записывает задачу; если запись ещё идёт, она сначала останавливается. Экран очищается для следующей задачи, под полем видно «Added to <список>». Крестик слева сверху (виден, когда есть текст или запись) очищает черновик.

Запись — обычный файл `Recording ГГГГММДДччммсс.m4a`, как у диктофона Obsidian. Он кладётся туда, куда Obsidian кладёт вложения (Settings → Files and links → Default location for new attachments), а в строку задачи пишется ссылка на него и тег для расшифровки:

```markdown
## Inbox
- [ ] Позвонить в банк
- [ ] [[Recording 20261106143200.m4a]] #transcribe
- [ ] Идея для поездки [[Recording 20261106151000.m4a]] #transcribe
```

Если есть и текст, и запись, текст идёт первым. Тег ставится только задаче с записью. Он задаётся в приложении: **Recording Tag**, по умолчанию `#transcribe`; пустое поле — без тега.

Siri, команды и виджеты (всё, что пишет задачу без экрана) проект не ставят, как не ставят метки и приоритет: такие задачи приходят без проекта.

## Откуда открыть

Экран новой задачи один, откуда его ни открой: печатать или записывать, решаешь уже на нём.

- **Иконка Tasks на главном экране.** Открывает [главный экран приложения](app.md) там, где его оставил; новая задача — **+** справа от таб-бара.
- **Виджет на экране блокировки.** Долгое нажатие на экран блокировки → **Customize** → **Lock Screen** → тап по полосе виджетов под часами → в списке приложений **Tasks** → круглый **New Task**. Тап по нему после Face ID открывает экран новой задачи.
- **Кнопка в нижнем углу экрана блокировки** (вместо фонарика или камеры) и **Пункт управления**: там же, **+** → Tasks → **New Task**.
- **Кнопка действия** (iPhone 15 Pro и новее): Settings → Action Button → **Shortcut** → Tasks → **New Task**.
- **Siri** (по-английски): «Hey Siri, add a task to Tasks» → Siri спрашивает «What's the task?» → диктуешь название → «Added to Inbox.» (с именем раздела из файла: «Added to Входящие.»), приложение не открывается. Годятся и «Add a task in Tasks», «Add task to Tasks», «Add task in Tasks», «New task in Tasks»; похожие формулировки iOS тоже старается понять. Имя приложения во фразе обязательно, а сказать название задачи той же фразой («add buy milk to Tasks») нельзя: так умеют только приложения с платной подписью Apple Developer Program.
- **Своя команда «Add a task»** — чтобы говорить Siri без имени приложения. Один раз в приложении «Команды» (Shortcuts): **+** → **Add Action** → найди **Tasks** → **Add Task** → тап по синему полю **Task** → **Ask Each Time** → вверху тап по имени команды → **Rename** → `Add a task` → **Done**. Потом «Hey Siri, add a task» → «What's the task?» → название → задача в Inbox.
- **Команды**: действия **New Task** (открыть экран) и **Add Task** (текст в Inbox) можно ставить и в другие свои команды.
- В самом приложении — **+** справа от таб-бара.

## Если не записалось

Пустую задачу (ни текста, ни записи) приложение не пишет. Ошибка видна красной строкой на экране новой задачи (Siri её произносит): нет доступа к папке волта — выбери её в приложении заново; нет файла задач — проверь Tasks file в настройках плагина. Текст и запись при этом остаются на экране, можно нажать Add ещё раз. Без разрешения на микрофон кнопка записи пишет, что его надо включить в Настройках.

## Проверка

1. Поставь на экран блокировки виджет **New Task** (см. выше). Заблокируй телефон, тапни виджет **New Task**: после Face ID открылся экран новой задачи, Inbox выбран, клавиатуры нет (так только с виджета: с плюса в приложении клавиатура открыта сразу).
2. Нажми микрофон, скажи пару слов, нажми паузу, потом снова микрофон, ещё пару слов, **Add**.
3. Открой Obsidian на iPhone: в конце Inbox задача `[[Recording …m4a]] #transcribe`; по ссылке запись играет целиком, с обоими кусками.
4. В приложении **+**: экран поднялся с открытой клавиатурой и курсором в поле. Переключи на **Now** → напиши «Проверка» → Add. В Obsidian задача в конце Now с сегодняшней датой.
5. «Hey Siri, add a task to Tasks» → «Buy milk». В Inbox появилась `Buy milk`.
6. «Hey Siri, add a task» (своя команда) → «Call mom». В Inbox появилась `Call mom`.
7. В приложении тапни **+**: поднялся экран новой задачи; смахни его вниз — снова главный экран, новая задача уже в своём списке.
8. В Obsidian переименуй Inbox в Settings → Sections (например, «Входящие»), дождись Sync, вернись в приложение: на переключателе «Входящие»; задача оттуда ложится под `## Входящие`, а «Hey Siri, add a task to Tasks» отвечает «Added to Входящие.».
