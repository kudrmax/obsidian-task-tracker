# Действия с задачами

Чекбоксов на экране нет. Тап по карточке (на Mac — клик или правый клик) открывает меню задачи. Долгое нажатие (на Mac — просто потянуть) поднимает карточку для перетаскивания. Каждое действие сразу пишется в файл и отменяется кнопкой отмены.

## Новая задача: быстрый ввод

Задача пишется прямо там, где окажется: в списке открывается поле ввода на её месте.

**Откуда открыть поле:**

| Действие | Где встанет задача |
|---|---|
| Тап по плюсу | конец колонки дня; в положении Inbox–Soon — конец Inbox |
| Потянуть плюс и отпустить между карточками | в это место; уровень (подзадача или нет) — по тому, насколько правее середины списка отпустили |
| Потянуть плюс на календарь | на это время выбранного дня, без длительности |
| Долгий тап по пустому месту календаря | на это время |
| Двойной клик мышью по пустому месту колонки (Mac) | конец этой колонки |
| Add subtask в меню задачи | последней подзадачей |
| Тап по плашке «No tasks» пустой секции | в эту секцию |

**В поле:**

- **Enter** сохраняет задачу и открывает пустое поле прямо под ней — так пишется пачка задач подряд.
- **Enter на пустом поле** заканчивает ввод (у подзадачи — сначала сдвигает поле на уровень влево).
- **Сдвиг**: Tab / Shift+Tab на Mac, кнопки «влево» и «вправо» в полосе на телефоне — поле становится подзадачей задачи выше или обратно.
- **Тап мимо** сохраняет написанное и заканчивает ввод. **Escape** (Mac) закрывает поле без сохранения.
- Префикс `p1 ` в начале текста сразу ставит приоритет.
- `[[` открывает поиск заметок, как в обычной заметке.
- **Кнопка секции** (первая в полосе) переключает поле: вместо задачи — имя новой секции (подсказка «Section name»). Enter ставит заголовок секции ровно на место поля: задачи ниже поля в той же группе уходят в новую секцию; в самом низу секция заводится пустой. Поле подзадачи при переключении встаёт на верхний уровень, после всех подзадач. Повторное нажатие возвращает поле к задаче. На Mac то же делает **⌥Tab**. Кнопка есть только в списках с секциями (Inbox, Backlog, Soon, колонка сегодня и будущего дня).

**Полоса над клавиатурой**: кнопка секции, кнопки сдвига, флажок приоритета, кнопка повтора и кнопка места. Пока поле пишет секцию, остаётся только кнопка секции. **На Mac** под полем две капсулы: слева — кнопка секции (по левому краю поля), справа — кнопки задачи; пока поле пишет секцию, правая прячется.

- Флажок — плитки уровней приоритета.
- Повтор — панель повтора (см. «Повтор» ниже).
- Место — Inbox, Backlog, Soon, Now или Date (выбор дня). Поле переезжает в конец выбранного списка или дня; колёсико само поворачивается, если надо.
- У подзадачи нет кнопки места (она живёт у родителя). У поля на календаре — только флажок.

**Что получает задача по месту:** Inbox и Backlog — без срока; Soon — без срока; Now — сегодняшний срок; другой день — его срок (в Now, если день не позже сегодня, иначе в Soon); на календаре — ещё и время.

## Меню задачи

Тап по карточке. Карточка остаётся над затемнённым фоном (с длинным названием целиком), под ней панель. Сверху вниз:

1. **Статус** — плитки Done, In progress (у задачи в процессе — Stop progress), Won’t do; у задачи с повтором ещё Stop.
2. **Приоритет** — плитка на уровень. Тап по другому уровню ставит его, по текущему — снимает.
3. **Перенос** — Today, Tomorrow, Pick a date. Плитки текущего дня задачи нет. Ставят срок на этот день и снимают время; задача встаёт в конец Now (сегодня) или Soon (позже). Pick a date открывает календарь месяца; внизу Remove due date — снять срок (у задачи на сегодня этой строки нет: сегодня — это Now).
4. **Правка**:
   - Rename — карточка сама становится полем ввода. Enter сохраняет; там же можно сменить приоритет и место. На Mac то же — двойной клик по карточке.
   - Reminder — у задачи со временем: вид напоминания на iPhone по кругу (уведомление → будильник → карточка на экране блокировки → без напоминания).
   - Add description — у задачи без описания.
   - Repeat — у открытой задачи верхнего уровня; справа текущее правило.
   - Section — у задачи списка, где есть секции: перенести в другую секцию или завести новую.
   - Add subtask — поле новой подзадачи.
5. **Open in Obsidian** — открыть файл задач на строке этой задачи.
6. **Delete** — удалить строку со всем вложенным.

Delete, Won’t do и Stop переспрашивают на месте: появляется вопрос с кнопками Cancel и подтверждением. На Mac Enter подтверждает, Escape закрывает меню.

Если у задачи есть описание, над карточкой показывается его начало. Тап по нему — экран описания, тап по ссылке в нём — открыть ссылку.

Тап по задаче на календаре, у которой есть подзадачи, показывает её открытые подзадачи между карточкой и меню; тап по подзадаче — её меню.

## Перетаскивание

Долгое нажатие на телефоне (по умолчанию 250 мс, есть лёгкая вибрация), на Mac — просто потянуть. Карточка едет за пальцем, на её месте остаётся пунктир. Место броска в списке показывает полоска между карточками; на календаре — линия с временем начала.

| Откуда → куда | Что меняется в файле |
|---|---|
| Внутри списка | порядок строк и уровень: левее середины списка — обычная задача, правее — на уровень глубже за каждый шаг отступа (подзадача), как у плюса |
| Inbox ↔ Backlog ↔ Soon | раздел; срок и время снимаются |
| Soon → колонка дня (сегодня) | в Now, срок сегодня |
| Колонка дня (сегодня) → Soon | в Soon, срок снимается |
| Soon → колонка другого дня | срок этого дня, задача остаётся в Soon |
| Колонка другого дня → Soon | срок снимается |
| Список → календарь | время с точки броска, без длительности; задача Now, брошенная на календарь другого дня, уходит в Soon без сегодняшнего срока |
| Внутри календаря | новое время, длительность сохраняется |
| Календарь → список | время стирается, срок остаётся; задача встаёт, куда бросили |
| На заголовок секции, между секциями | в эту секцию |

- У края списка или календаря он прокручивается сам — задачу можно донести туда, чего не видно.
- Задача с подзадачами едет вместе с ними.
- Перенос на другой день — только меню (Tomorrow, Pick a date), не перетаскиванием.

**Длительность.** Тап по задаче на календаре открывает меню и выделяет её: на краях карточки две точки. Потянул точку — меню закрывается, верхняя точка двигает начало, нижняя — конец, с шагом привязки. Стянутая до минимума задача теряет длительность.

## Секции

- **Завести с задачей**: меню задачи → Section → заготовка (по умолчанию Morning, Afternoon, Evening) или New section и имя. Задача встаёт в новую секцию.
- **Завести сначала секцию**: плюс (тап, или потянуть в нужное место), на Mac — двойной клик по пустому месту колонки; в полосе — кнопка секции, имя, Enter. Посередине списка заголовок делит группу: задачи ниже уходят в новую секцию. Внизу секция пустая.
- **Пустая секция** — заголовок и под ним пунктирная плашка «No tasks». Задачу бросают прямо на плашку — она загорается, задача встаёт в секцию. Тап по плашке — поле новой задачи в этой секции. Пустую секцию переставляют, переименовывают и удаляют, как любую.
- **Перенести задачу** между секциями: перетаскиванием или через Section в меню. Section предлагает секции списка, видные на экране, пустые тоже, и заготовки. Выбор секции, в которой задача уже стоит, ничего не меняет; в меню нескольких задач переезжают только те, что ещё не в ней.
- **Тап по заголовку секции** — меню: Rename (имя правится на месте) или Remove section.
- **Долгое нажатие на заголовок** поднимает всю секцию — её можно переставить среди других.
- Секция исчезает сама, когда из неё унесли последнюю задачу. Созданная пустой — остаётся, пока её не удалят.
- Пустая секция Soon видна в колонке Soon и в колонке каждого будущего дня: в файле у неё нет дня. Как только в неё легла задача, она видна только там, где видна задача.
- Задачи вне секций, когда в списке есть секции, собираются под заголовком «No section».
- Колонка дня показывает секции Now на сегодня и секции Soon на будущий день: вечером можно разложить завтрашний день по секциям, утром они будут в Now в тех же секциях.

## Подзадачи

- Сделать: Add subtask в меню, сдвиг при вводе (Tab или кнопка), перетаскивание под карточку со сдвигом вправо.
- Счётчик на родителе — сколько прямых подзадач сделано.
- Подзадача, унесённая в другую колонку или на календарь, становится обычной задачей.
- На календаре подзадачи в блоке не рисуются, только счётчик.

## Описание

- Add description или тап по началу описания над карточкой открывает экран описания на всё окно: название и описание целиком.
- Edit или тап по тексту — правка в редакторе Obsidian (тот же, что в заметках, с панелью над клавиатурой). Save записывает, Cancel — нет. Пустое описание убирает его.
- Ссылки, картинки и разметка рисуются, как в заметке.

## Повтор

Ставится кнопкой повтора при вводе или строкой Repeat в меню. Панель:

- Переключатель **Schedule** (по расписанию) / **After done** (от последнего раза).
- **Every N** кнопками − и +, единица days / weeks / months.
- Для недель по расписанию — дни недели (хотя бы один); для месяцев — число.
- **Remove repeat** — снять повтор, не закрывая задачу.

Из меню правило пишется в файл один раз, когда меню закрывается. Повтор по расписанию у задачи без даты сразу даёт ей срок — ближайший подходящий день. Что делают Done, Won’t do и Stop — в [Файл задач → Повтор](file.md#повтор).

## Массовые действия

**Select tasks** (телефон и Mac): «⋯» в капсуле слева внизу → Select tasks.

- На каждой задаче в списках появляется кружок. Тап по задаче ставит или снимает галку, меню задачи не открывается. Выбирать можно в Inbox, Backlog, Soon и Now сразу: колёсико и свайп работают. Задачи на календаре не выбираются.
- Вместо капсулы «отмена + ⋯» — капсула с крестиком (выйти) и числом выбранных; вместо плюса — круг с «⋯». Пока ничего не выбрано, число и «⋯» погашены.
- Тап по «⋯» (или по числу) — меню на все выбранные (как ниже). Долгое нажатие на выбранную уносит все стопкой.
- Крестик, Esc или любое действие над выбранными закрывают режим выбора. Тап мимо карточек выбор не снимает.

**⌘-клик** (только Mac):

- ⌘-клик выделяет карточку, Shift-клик — подряд. Можно в разных списках. Задачи на календаре не выделяются.
- Клик по выделенной — меню на все: «N tasks», статус, приоритет, перенос, Section (если все из одного списка с секциями), Delete N tasks.
- Перетаскивание любой выделенной уносит все стопкой; на календарь стопку не положить.
- Esc, клик мимо или любое действие снимают выделение. Esc во время переноса отменяет перенос.

## Поиск

- «⋯» в нижнем ряду, рядом с кнопкой отмены → Search открывает поиск; на Mac ещё Cmd+F, когда фокус в календаре.
- На телефоне поле стоит над клавиатурой, найденное — над ним; Cancel закрывает. На Mac панель сверху по центру: стрелки выбирают строку, Enter открывает, Esc или клик мимо закрывают.
- Ищет по названиям и описаниям всех задач и их открытых подзадач во всех разделах: Inbox, Backlog, Soon, Now (любой день), Done. Регистр не важен, «ё» и «е» — одно. Ссылки ищутся по тому, что видно на карточке.
- Найденное сгруппировано по разделам. Слово в названии подсвечено; если слово нашлось в описании, под названием строка из описания со значком описания.
- Тап по найденному ведёт экран к задаче: Inbox и Backlog — к Inbox–Soon, Soon без даты — к Soon–Now, задача с датой или из Now — к её дню рядом с календарём, Done — в колонку Done. Карточка обведена, пока не коснёшься экрана.

## Отмена

- Кнопка в левом нижнем углу отменяет последнее действие; несколько нажатий — несколько шагов (до 100). Погашена, когда отменять нечего.
- На Mac Cmd+Z и Cmd+Shift+Z (повтор отменённого), когда фокус в календаре, а не в поле ввода.
- Отменяется каждое действие в календаре, одно действие — один шаг (Done с повтором — тоже один: уберёт и отметку, и копию).
- Не отменяются ручные правки файла, изменения через Sync и автоматические переносы утром.
- Если те же строки с тех пор правили руками или через Sync — «Can’t undo: the tasks file changed», шаг пропадает.
- История живёт в памяти и пропадает при перезапуске Obsidian.
