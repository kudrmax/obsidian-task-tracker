# Уведомления на iPhone

Задача, поставленная на время, звенит на телефоне в момент начала: название задачи, под ним время, тап открывает Obsidian. Это делает скрипт Scriptable `Task Notifications`: он читает файл задач тем же разбором, что и плагин, и держит по одному уведомлению на каждую незакрытую задачу со временем в Now и Soon. Задача, которую перенесли, сняли со времени, закрыли или отменили, теряет старое уведомление при следующем запуске. Одна дата без времени не звенит.

Скрипт вставляется в Scriptable целиком. После изменений в нём (новый релиз с правкой уведомлений) его нужно вставить заново.

**С версии с повторяющимися задачами вставь скрипт заново.** Старый скрипт не знает метку повтора `🔁`: задача с повтором и временем у него теряет уведомление. В новом скрипте в `SETTINGS` у маркеров появился `repeat: "🔁"`. Если ты менял маркеры в `SETTINGS` под себя, после вставки поправь их снова, а `repeat` поставь таким же, как эмодзи повтора в настройках плагина.

## Часть 1. Scriptable

1. На iPhone открой в Safari <https://raw.githubusercontent.com/kudrmax/obsidian-task-tracker/master/scriptable/Task%20Notifications.js>, выдели весь текст и скопируй.
2. Scriptable → **+** → новый скрипт с именем ровно `Task Notifications`, вставь текст, нажми **Done**. Если путь к файлу задач, названия секций или маркеры в плагине не по умолчанию, поправь их в `SETTINGS` в начале скрипта.
3. Закладка `ObsidianVault` в Scriptable → шестерёнка → **File Bookmarks** нужна та же, что для рабочего календаря ([work-calendar.md](work-calendar.md), часть 1, шаг 3).
4. Нажми на скрипт, чтобы запустить его один раз. iOS попросит разрешить уведомления, разреши. Окно покажет, сколько задач впереди.

## Часть 2. Автоматизация

Скрипт запускается при закрытии Obsidian: в этот момент файл содержит твои последние правки и то, что Sync принёс с Mac. Obsidian синхронизируется только пока открыт, поэтому задача, поставленная на время на Mac, доходит до телефона, когда ты в следующий раз откроешь и закроешь там Obsidian.

Как и для рабочего календаря, закладка из настроек Scriptable в фоне недоступна, поэтому автоматизация сама создаёт закладку на папку волта.

5. «Команды» → вкладка **Automation** → **+** → **App** → выбери Obsidian, отметь **Is Closed** (и сними Is Opened), выбери **Run Immediately**, выключи **Notify When Run** → Next → **New Blank Automation**.
6. Добавь действие **File** (ровно «File», синяя иконка; не Get File, не Select File). Нажми на синее слово «File» → Browse → On My iPhone → Obsidian → зайди внутрь папки волта → **Open** справа вверху.
7. Добавь действие Scriptable **Create File Bookmark**: поле файла — плашка **File** над клавиатурой (результат шага 6), Name — `ObsidianVault`.
8. Добавь действие Scriptable **Run Script** → `Task Notifications`, раскрой стрелку и выключи **Run In App**. Нажми **Done**.

## Часть 3. Чтобы не пропускать

9. Настройки iPhone → Notifications → Scriptable → **Sounds** включены, Banner Style **Persistent** (баннер висит, пока не смахнёшь).
10. Для каждого фокуса, которым пользуешься днём: Настройки → Focus → фокус → Apps → Allowed Apps → **+** → Scriptable. Иначе уведомление придёт без звука.

## Для разработчика

Скрипт собирается из `src/scriptable` командой `node scriptable/build.mjs` (входит в `npm run build`). Тест падает, если закоммиченный скрипт устарел.
