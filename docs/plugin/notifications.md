# Напоминания на iPhone

Задача со временем напоминает о себе ровно в начало: тихим уведомлением или будильником. Без времени напоминания нет. Это делает приложение Task Calendar для iPhone (репозиторий `kudrmax/task-calendar-ios`). Оно читает файл задач тем же разбором, что и плагин, своего хранилища у него нет.

Вид напоминания задаёт эмодзи перед временем:

- `⏰` — тихое уведомление. Повторяется, пока не нажмёшь кнопку, но не дольше конца дня задачи.
- `🚨` — будильник: на заблокированном телефоне на весь экран, на разблокированном плашкой сверху; фиолетовый, чтобы не путать с будильником «Часов». По умолчанию без звука, звук включается в приложении (**Alarm Sound**); со звуком звонит сквозь беззвучный режим и фокус.
- `🔕` — без напоминания.

Переключить вид у задачи на время: меню задачи → **Reminder** (Notification → Alarm → Off по кругу), или поменять эмодзи в строке руками. Сами эмодзи меняются в настройках плагина: Slot marker, Alarm marker, No-reminder marker.

Кнопки уведомления (долгое нажатие): **Done** закрывает задачу, **15 min**, **30 min**, **1 hour** переносят её на столько от текущего момента. Тап открывает календарь в Obsidian.

Пятая кнопка, **After «встреча» (через сколько)**, переносит задачу на конец ближайшей встречи, например «After Design review (1 h 30 min)». Ближайшая — та, что идёт сейчас, или следующая. Время в скобках считается от момента, когда пришло уведомление. Встречи те же, что на таймлайне плагина: приложение читает файлы `calendar/google.json` и `calendar/work.json` (см. [Календари](calendars.md)), к календарям iPhone оно не обращается. Берутся встречи со временем, без событий на весь день. Если до конца дня задачи встреч больше нет, кнопки нет: на завтра задача так не уедет.

У будильника две кнопки. «Сдвинуть, чтобы остановить» выключает напоминание задачи: в строке `🚨` меняется на `🔕`, время и сама задача остаются, больше по ней ничего не приходит. Если потом убрать задачу со времени и поставить снова, она получит `⏰`; перенос по таймлайну `🔕` сохраняет. **Snooze** переносит задачу на интервал из настроек приложения (по умолчанию 30 минут) и звонит снова. Если будильник замолчит сам, без кнопки, дальше идут тихие уведомления задачи.

Задача с повтором (`🔁` в конце строки) напоминает так же. **Done** на её уведомлении закрывает её, и сразу же в файле появляется следующая копия (её пишет и плагин на Mac, и приложение на iPhone): на следующий день по правилу, без времени, поэтому и без напоминания.

**С версии с повторяющимися задачами обнови приложение на iPhone:** собери его с этой версией плагина и нажми Run в Xcode, как в шаге 3. Старое приложение не знает метку `🔁`: задача с повтором и временем у него теряет напоминание. Метку повтора приложение берёт из настроек плагина (Repeat marker), отдельно её вписывать не нужно.

## Часть 1. Поставить приложение

1. На Mac нужен Xcode 26 или новее (App Store). В Xcode → Settings → Accounts добавь свой Apple ID.
2. Склонируй `task-calendar-ios` вместе с плагином: `git clone --recurse-submodules https://github.com/kudrmax/task-calendar-ios.git`, затем `brew install xcodegen` и `xcodegen generate` в папке репозитория.
3. Подключи iPhone кабелем, открой `TaskCalendar.xcodeproj`, в таргете TaskCalendar → Signing & Capabilities выбери свою команду (Personal Team), выбери iPhone и нажми Run.
4. Первый раз iPhone не запустит приложение: Настройки → Основные → VPN и управление устройством → твой Apple ID → Доверять.
5. Бесплатная подпись живёт 7 дней. Раз в неделю подключай iPhone и снова нажимай Run в Xcode: данные и настройки сохраняются. С истёкшей подписью приложение не запускается, а кнопки напоминаний не работают.

## Часть 2. Настроить приложение

6. Открой Task Calendar на iPhone → **Vault Folder** → On My iPhone → Obsidian → зайди внутрь папки волта → **Open**.
7. Нажми **Allow** у Notifications и у Alarms.
8. Строка **Reminders** покажет, сколько напоминаний поставлено. Если там ошибка, она скажет, чего не хватает. Приложение на английском.
9. Нужен звук у будильников — включи **Alarm Sound**. Здесь же **Snooze Alarm For**: на сколько Snooze переносит задачу.

## Часть 3. Автоматизация: обновлять при выходе из Obsidian

Файл задач на iPhone меняется, только пока Obsidian на экране: там твои правки, и Sync в этот момент приносит правки с Mac. Поэтому приложение пересобирает напоминания каждый раз, когда ты уходишь из Obsidian: на главный экран, в другое приложение или блокируешь телефон. Перезапускать Obsidian не нужно.

10. «Команды» → **Automation** → **+** → **App** → выбери Obsidian, отметь **Is Closed** (сними Is Opened), выбери **Run Immediately**, выключи **Notify When Run** → Next.
11. Добавь действие **Update Reminders** (приложение Task Calendar) → Done.
12. На iOS 27 автоматизации лежат в Library → Automation: у этой выключи **Confirm Before Run** и включи **Allow Running When Locked**.

## Часть 4. Чтобы не пропускать

13. Настройки iPhone → Notifications → Task Calendar: **Allow Notifications** включены, Banner Style **Persistent** (баннер висит поверх всего, пока не нажмёшь), **Scheduled Summary** выключена.
14. Для каждого фокуса, которым пользуешься днём: Настройки → Focus → фокус → Apps → Allowed Apps → **+** → Task Calendar. Иначе в фокусе уведомление не всплывёт. Будильнику это не нужно.

## Проверка

15. В Obsidian на iPhone поставь задачу на время через 2 минуты с `⏰` и выйди на главный экран. Через 2 минуты должно прийти уведомление без звука.
16. Долгое нажатие → **15 min**. Открой Obsidian: задача переехала на 15 минут позже.
17. Заведи в Google Calendar встречу через полчаса на час и открой календарь в Obsidian на iPhone: встреча появилась на таймлайне. Поставь задачу через 2 минуты и выйди из Obsidian. В уведомлении есть кнопка «After <встреча> (1 h 28 min)» или около того. Нажми её: задача переехала на конец встречи.
18. То же с `🚨`: звонит будильник. Сдвинь, чтобы остановить: задача осталась на своём времени с `🔕`, уведомлений по ней больше нет.

Если уведомление не пришло, открой Task Calendar и посмотри строки Reminders и Updated или текст ошибки. Если в «Командах» автоматизация не срабатывает, проверь шаг 12. После перезагрузки iPhone автоматизации работают только после первой разблокировки.

## Для разработчика

Приложение берёт из плагина один файл: `phone/task-calendar-phone.js`. Он собирается из `src/phone` командой `node phone/build.mjs` (входит в `npm run build`). Тест падает, если закоммиченный файл устарел.
