# Экран

Один вид Obsidian: открывается кнопкой в боковой панели или командой «Open Task Calendar». Можно открыть в нескольких вкладках — всё, что сделано в одной, сразу видно в другой.

## Лента колонок

Экран — окно на две колонки над лентой из четырёх:

```
[ Inbox    ]  [ Soon ]  [ Now ]  [ календарь дня ]
[ Backlog  ]
```

Окно стоит в одном из трёх положений:

| Положение | Слева | Справа | Для чего |
|---|---|---|---|
| Inbox и Soon | Inbox над Backlog | Soon без даты | разбор входящего |
| Soon и Now | Soon без даты | колонка дня | что взять на день |
| Now и календарь | колонка дня | таймлайн дня | основной экран: план дня по времени |

- **Inbox над Backlog** — одна колонка, поделённая пополам: сверху Inbox, снизу Backlog со своим заголовком. Списки листаются каждый сам.
- **Soon** показывает только задачи раздела Soon без даты и без времени. Задачи Soon с датой видны в колонке своего дня.
- **Колонка дня** — список выбранного дня. Сегодня — раздел Now (без задач, уже стоящих на сегодняшнем календаре). Другой день — задачи с этим сроком, без задач, стоящих на календаре этого дня. На прошлом дне — то, что на него назначено, без секций.
- В положениях Inbox–Soon и Soon–Now колонки делят экран поровну. В положении Now–календарь между ними разделитель с ручкой: его тянут, чтобы сделать список шире или уже. Ширина запоминается на устройстве.
- Положение окна тоже запоминается на устройстве (не синхронизируется).
- **Край прокрутки.** Карточки, ушедшие под заголовок колонки при прокрутке, не обрезаются линией, а мягко растворяются на высоте около половины карточки. То же у нижнего края списка, пока ниже есть ещё задачи (например, у Inbox над Backlog), и у таймлайна. Список, который стоит в самом начале, сверху не растворяется.

## Группы проектов

Backlog (и Soon, если включить) может показывать задачи по проектам.

- Каждый проект — своя группа: заголовок как у секции, перед ним шеврон. Тап по заголовку сворачивает и разворачивает группу; у свёрнутой справа от имени число её открытых задач. Свёрнутость запоминается на устройстве.
- Стрелка рядом с именем (та же, что у Open in Obsidian) открывает заметку проекта в новой вкладке. Сам заголовок заметку не открывает. У «No project» стрелки нет.
- Группы идут по алфавиту, «No project» — задачи без проекта — всегда последней.
- Внутри группы сначала задачи проекта без секции (без заголовка), потом секции проекта в порядке файла. Секция в файле одна на всех: «Дальний бэклог» видна внутри каждого проекта, у которого там есть задачи. Пустые секции видны только внутри «No project».
- В Backlog группа есть у каждого проекта, даже без задач там: тогда в ней плашка «No tasks», на неё можно бросить плюс или задачу. В Soon группа есть только у проектов, у которых там есть задачи.
- **Включить и выключить**: тап по заголовку колонки «Backlog» или «Soon» открывает меню с одной строкой Group by project и галкой. По умолчанию Backlog сгруппирован, Soon нет. Запоминается на устройстве (не синхронизируется). Inbox, Now и колонки дней по проектам не группируются никогда.
- Выключено — список как раньше, задачи проектов с меткой папки.

## Колёсико

Внизу по центру — переключатель из четырёх иконок: Inbox, Soon, Now, календарь. Плашка на нём показывает, какие две колонки в окне.

- Тап по иконке вне окна поворачивает ленту к ближайшему положению, где она видна.
- Колёсико крутится и пальцем: быстрый свайп — ровно на одно положение, медленное ведение — свободно, с докатом до ближайшего.
- Долгое нажатие, когда открыт календарь, открывает окно источников календарей ([Календари](calendars.md)).
- Оранжевая точка на иконке календаря — какой-то источник давно не обновлялся или вернул ошибку.

Слева внизу — капсула с кнопкой отмены и «⋯» (в нём Search — поиск и Select tasks — выбор нескольких задач), справа — плюс (новая задача). См. [Действия с задачами](tasks.md).

## Колонка Done

Слева от Inbox есть колонка Done — сделанные и отменённые задачи в порядке файла. Колёсиком и свайпом туда не попасть: её открывает только поиск, когда находит задачу из Done. Свайп или колёсико уводят с неё на Inbox, и она пропадает до следующего поиска. Тап по карточке в Done открывает обычное меню задачи.

## Свайп по экрану и дни

Экраны стоят в один ряд:

```
Inbox–Soon  ←  Soon–Now  ←  Now–календарь (сегодня)  →  календарь завтра  →  послезавтра  → …
```

- Свайп по содержимому экрана (на Mac — двумя пальцами по трекпаду) ведёт по этому ряду: экран идёт за пальцем, отпущенный встаёт на ближайший. Вправо от сегодняшнего календаря — следующие дни.
- При смене дня двигается только сам день; заголовок и часы стоят.
- Над колонками — заголовки. У колонки дня заголовок `Today`, `Tomorrow`, `Yesterday` или дата, по бокам стрелки на день назад и вперёд. Тап по заголовку возвращает на сегодня.
- Выбранный день задаёт и колонку дня, и таймлайн.

## Таймлайн

Правая колонка в положении Now–календарь — шкала выбранного дня.

- Показывает 24 часа: от начала дня (по умолчанию 5:00) до того же часа следующего утра. Прокручивается. Сегодня открывается так, что линия «сейчас» стоит чуть выше середины; другой день — на часе из настроек (по умолчанию 9:00).
- **События** календарей Google и рабочего — цветные блоки, только для чтения. Пересекающиеся ложатся друг на друга со сдвигом вправо. Прошедшие события блекнут. События на весь день — строки над таймлайном.
- **Задачи со временем** — те же карточки, что в списке. Без длительности — карточка обычной высоты; с длительностью — высотой по длительности. Задачи, которые стоят тесно, складываются в стопку, время начала тогда подписано справа.
- **Линия «сейчас»** — красная, с капсулой времени, только на сегодня. Несделанная задача, чьё время уже прошло, едет за линией: стоит на ней и сдвигается каждую минуту. Время в файле при этом не меняется.
- **Масштаб** — щипком (на Mac Ctrl+колесо или щипок трекпада). Останавливается там, где отпустили пальцы, от «весь день на экране» до самого крупного часа из настроек. Масштаб запоминается на устройстве.
- **Шаг привязки** при перетаскивании и растягивании следует из масштаба: мелкий масштаб — 30 минут, обычный — 15, крупный — 5.

## Карточка задачи

- Капсула с названием. Длинное название гаснет к правому краю; в меню и под пальцем показывается целиком.
- Справа — срок (число и месяц). Срока нет у задачи с датой открытого дня: он и так понятен.
- Значок повтора рядом с числом срока.
- Счётчик подзадач «2/5» и значок описания — перед сроком.
- Значок папки цвета подписей — задача из проекта. Стоит на месте срока и той же ширины, левее срока, повтора и счётчика, если они есть; высота карточки не меняется. Тап по значку открывает заметку проекта, тап по остальной карточке — меню, как всегда. Какой это проект, видно в меню задачи (строка Project), на Mac — в подсказке при наведении. Значок есть везде, где есть карточка: в списках, в группах проектов, на календаре, у подзадач (проект родителя). Его нет только в блоке внутри заметки проекта: там весь экран — этот проект. В режиме выбора нескольких задач тап по значку выбирает задачу.
- Точка слева — задача в процессе.
- Фон цвета приоритета — у задачи с приоритетом. Задача с одной меткой окрашена так же, цветом метки. С несколькими — косыми полосками их цветов или переливом от одного к другому (настройка Several labels).
- Подзадачи — сразу под задачей, со сдвигом вправо и линиями-ветками, как дерево папок. Тап по счётчику прячет их; у свёрнутой задачи из-под карточки выглядывает край второй.
- Заголовки секций — над группами задач.

## Экран в заметке проекта

В конце каждой заметки проекта плагин сам показывает свой экран — только с задачами этого проекта. В заметку при этом ничего не пишется: это не текст, а вид, как встроенные в документ бэклинки Obsidian. Работает в Reading view и в Live Preview, на Mac и на телефоне.

- Те же колонки, колёсико и жесты, что на главном экране: Inbox над Backlog, Soon, колонка дня, календарь; свайп и колёсико листают, тап — меню, перетаскивание — перенос, плюс — новая задача. Пустая колонка показывает плашку «No tasks».
- Блок начинается сразу под текстом заметки, с обычным отступом абзаца, и в Live Preview, и в Reading view. Внутри рамки заголовки колонок и карточки стоят с отступами, как на главном экране; колёсико и плюс внизу блока не уходят под строку состояния Obsidian на Mac и под его панель на телефоне.
- Блок в рамке, высотой по своим задачам: столько, сколько занимает самая длинная из двух видимых колонок, плюс колёсико внизу. У проекта с парой задач блок короткий (не ниже, чем на макете), у большого — растёт до высоты экрана телефона без панелей Obsidian, и дальше списки листаются внутри блока. Пока видна колонка календаря, блок всегда этой наибольшей высоты: в ней весь день. Высота меняется сама, когда задачи добавляются или уходят и когда поворачивается колёсико; во время перетаскивания карточки блок не меняется. Inbox и Backlog в блоке стоят друг под другом по своему содержимому, а не пополам.
- Своё положение колёсика, свой день и свой разделитель у каждой заметки; открывается на Inbox и Soon. Положение запоминается на устройстве для каждой заметки и переезжает вместе с заметкой при переименовании или переносе (и её папки); у удалённой заметки оно забывается.
- Блок стоит в конце заметки и при переключении Reading view / Live Preview любым способом (кнопкой, командой, горячей клавишей). В отдельном окне Obsidian блок работает так же, как в главном.
- На календаре — события дня, как на главном экране.
- Метки проекта на карточках нет, группировки по проектам нет.
- Всё, что сделано в блоке, пишется в файл задач по правилу видимого соседа: задача встаёт прямо перед той видимой задачей, перед которой её бросили, или сразу после последней видимой; если видимых нет — туда, куда её положил бы главный экран. Новая задача получает `🗂️` этого проекта.
- Блок — это одна группа проекта: секции в нём трогают только задачи проекта (Rename и Remove section — как внутри группы проекта, секции не переставляются), кнопка секции в поле ввода спрашивает имя, потом первую задачу.
- ⌘Z, ⌘⇧Z и ⌘F действуют на блок, только когда фокус в нём (после тапа или клика по блоку, в его поле ввода или описании); иначе это клавиши заметки. Поиск из блока ищет только задачи этого проекта. Клавиши редактора (⌘B, ⌘K…) в поле ввода блока правят поле, а не заметку. Клавиши, которые меняют саму строку (⌘L — чекбокс, списки, заголовки, цитаты, перенос строк вверх-вниз), в поле названия и в описании задачи — и в блоке, и на главном экране — ничего не делают: название — одна строка файла задач, а лишний `- [ ]` превратил бы её в другую задачу. Если такой значок всё же попал в начало названия (вставкой), плагин уберёт его при записи; жирный, курсив и ссылки в названии остаются.
- ⌘Z и ⌘⇧Z в поле поиска и в поле имени секции отменяют и возвращают набранное в этом поле.
- Внизу блока — колёсико и плюс; капсулы отмены и «⋯» в блоке нет: отмена — ⌘Z (или на главном экране).

## Тема и платформы

- Тёмная и светлая тема следуют за Obsidian, своей настройки нет.
- На телефоне всё делается пальцем: тап — меню, долгое нажатие — перетаскивание.
- На Mac: клик — меню, правый клик — тоже меню, перетаскивание начинается сразу. Есть клавиши, двойной клик по пустому месту списка (новая задача) и массовые действия (⌘-клик). Выбор нескольких задач через «⋯» → Select tasks — на обеих платформах.
